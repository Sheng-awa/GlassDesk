# 陪伴与 UI 视觉修订 · 2026-10-15

本页记录用户确认前的陪伴与布局修订。用户随后已指派液态玻璃、实机驻留与统一发布收尾；最新验收结论以 [验收报告](test-report.md) 为准。这里的单陪伴球、位置固定尺寸和播放器布局继续保留。

## 陪伴

- 取消固定 8 秒轮播。展开、指针接近、按压、拖动、释放、切歌、播放与暂停触发表情回应。
- 眼形、眼睑、视线与身体姿态同时过渡；开心为弯曲笑眼，困倦为半闭眼，好奇左右眼有不同开合。
- 闲置采用不规则短眨眼、偶尔双眨、短暂注视和极少的安静情绪片段。隐藏暂停；简化动画时保持静态。
- 胶囊的陪伴槽由 24 增为 32 DIP，左边距由 12 调到 18 DIP。
- 只显示一个陪伴球，每次展开随机选择不同位置；每个位置绑定固定尺寸，音乐小展开为 44／40／36／36 DIP，大展开为 52／40／36／36 DIP。移动、尺寸与表情同步过渡，从当前位置和速度衔接，身体与眼睛留在外壳内。小展开显示居中的系统时间，大展开不显示时间或媒体操作回执。

## 布局与显示

| 形态 | 尺寸 DIP | 当前布局 |
|---|---|---|
| 时钟胶囊 | 200 × 52 | 默认仅 HH:mm；时间、日期、星期分别开关 |
| 音乐胶囊 | 208–296 × 52 | 32 DIP 陪伴、歌曲／歌手、真实频段 |
| 时钟小展开 | 240 × 144 | 时钟与连接入口，单个陪伴随机选择边缘落点 |
| 音乐小展开 | 320 × 176 | 上方留陪伴活动带，左封面、中歌曲、右频段，下方控制 |
| 未连接音乐的大展开 | 280 × 232 | 连接说明与入口，单个边缘陪伴，不显示时间 |
| 音乐大展开 | 320 × 440 | 居中封面、歌曲、播放控制，左下角留空 |

展开外壳与设置主体统一 24 DIP 圆角，封面 20 DIP，胶囊、圆形按钮及浮动导航采用半高圆角。间距沿用 4／8／12／16／24 DIP。

## 基础磨砂与设置

基础 HostBackdrop 继续采样真实桌面；白色染色默认由 .62 降为 .24，取消顶部额外遮白和大面积文字底板。液态玻璃的采集和着色器没有在本轮修改。

设置改用真实 Desktop Acrylic、两列浅白胶囊控件和独立底部导航。同一 GPU 遮罩把玻璃裁成面板与导航两块，间隙透出真实桌面。导航共用选中底板，可拖动，释放时从当前位置和速度平滑落位；页面与底板同步连续移动。窄窗口自动堆叠为一列。

视觉预览使用独立配置目录，采用这轮默认透明度、仅时间和关闭液态玻璃。原安装配置保留。
