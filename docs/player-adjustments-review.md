# 播放器调整预览

本轮以最新两张截图为准，沿用现有玻璃、配色和圆角。

- 小展开的本地时间按卡片水平居中。日期和星期仍由现有设置分别控制。
- 大展开不显示时间，也不在卡片底部显示媒体操作回执。连接问题保留在设置里。
- 始终只显示一个陪伴球。每次展开随机选择不同的落点，落点绑定固定尺寸，不连续选择同一位置。音乐小展开的左上、右上、右侧、右下分别为 44、40、36、36 DIP；大展开的左上、右侧上部、右侧下部、右下分别为 52、40、36、36 DIP。角色始终留在卡片内，封面、歌曲文字和控制留有独立区域。
- 切换时沿用保留当前位置与速度的 MotionController，移动和尺寸在 650 毫秒内平滑衔接；眼形、眼睑和朝向同时过渡，落位后恢复自然的陪伴表情。快速收起或再次展开可以中断并重定向；减少动态效果时直接落位。
- 播放按钮按下时在 65 毫秒内缩到 94%，快速点击仍保留至少 90 毫秒的按压过程，随后在 180 毫秒内回弹；键盘和无障碍触发也有完整的 260 毫秒反馈。播放三角与暂停双条以 220 毫秒矢量路径变形切换，跟随实际播放状态。反馈层和图标跟随按钮一起缩放。媒体命令直接执行，不等待动画。
- “陪伴球跟随鼠标”使用现有设置保存机制。胶囊状态每 33 毫秒读取当前 Windows 桌面的系统鼠标坐标；离开胶囊后继续跟随，眼睛平滑限幅。关闭跟随、隐藏组件或启用减少动态效果时停止轮询。
- 系统减少动态效果设置与应用中的“简化动画”共同生效。

鼠标坐标读取限于当前 Windows 输入桌面，不尝试跨越锁屏或安全桌面。使用系统光标 API，不安装全局鼠标钩子、不记录鼠标轨迹。

当前网易云音乐客户端没有提供有效播放时间轴，因此继续隐藏歌曲进度条；小展开显示的是独立系统时钟。

本页记录当时的播放器调整范围。用户随后已指派液态玻璃、实机驻留和统一发布收尾；当前完成情况及未验证环境见 [验收报告](test-report.md)。

2026-10-15 播放交互补充验证：原生桥和应用 Release 构建通过；在网易云音乐实际连接下检查了小展开、大展开的播放／暂停状态与图标。小展开持续按压时，截图确认按钮保持中心并缩小，释放后恢复，实际播放操作正常。快速点击保留完整按压过程；键盘和无障碍调用使用相同反馈入口。系统及应用的减少动态效果开关继续控制动画。
