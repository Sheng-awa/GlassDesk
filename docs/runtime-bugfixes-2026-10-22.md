状态：实现与普通检查完成，独立试用版已生成；真实网易云快捷键场景等待用户复测。本轮没有做正式发布计划、安装包或设置 UI 重设计。

## 网易云外部快捷键：播放图标延迟

用户反馈：通过网易云自己的快捷键暂停 / 恢复时，GlassDesk 的播放状态与图标不立即变化，过一会才恢复。

发现的代码原因：原来的播放状态事件和异步元数据 / 封面读取共用 RefreshLoop，正在等封面时，后来的播放事件只能排队。这是一条已确认的延迟路径；没有把用户猜测的“快捷键显示冲突”直接当作根因，也没有通过音量 / 音频静默猜测暂停。

修复：
- PlaybackInfoChanged 立即走独立的状态读取；TimelinePropertiesChanged 也不再等待封面队列。
- 元数据等待期间，播放 / 暂停状态可以独立发布；封面结果仍受会话代次与内容版本保护。
- 组件可见、已连接网易云时，每 500 ms 补读一次系统播放状态。隐藏和退出时停止；不读取封面、不解码图片、不读取其他播放器。
- 状态、能力、速率与时间轴可用性没变时，不因单调时间戳前进而重绘整个组件。
- GlassDesk 自己发出的媒体命令也立即发布实际回读状态。
- 诊断环增加不含歌曲名 / 账号的播放状态变化记录。

**边界**：500 ms 是本应用的补读间隔，不是承诺网易云在所有情况下 500 ms 内发布真实 SMTC 状态。如果客户端自身延迟提供状态，需要用户复测与诊断进一步区分。本轮没有操作用户播放器，因此没有把真实快捷键问题写成“已实机验收通过”。

## 审查问题的处理情况

| 原审查项 | 本轮处理 |
|---|---|
| R01 旧平台断言 | 正常创建、损坏恢复、超大文件恢复的默认数量统一为当前的一张时钟；保留持久化与备份检查 |
| R02 原生批次混用 | 从当前源码重建 DLL 与 worker；构建前检查当前字体 ABI 导出，明确拒绝旧 DLL；复制改为 Always，避免输出目录的新旧时间戳掩盖输入来源 |
| R03 默认值覆盖数据 | widgets.json 与 settings.json 增加写入保护；读取 / 必要备份未成功时只用临时值，不允许覆盖原文件；显式成功重读后才恢复写入 |
| R04 深色字与透明材质冲突 | 移除 Details 强制深色字；直接画在外壳上的文字恢复材质适配；首页应用标签独立适配，已有浅色导航 / Dock / 文件夹弹层维持自身的深色 panel ink |
| R05 退出与清理 | 退出有统一异常 / finally 出口；单项资源释放失败不跳过后续释放；保存失败时可选择返回设置；插件退出等待设 8 秒上限并观察迟到异常 |
| R06 隐藏频谱仍采集 | Details 不再启用不可见频谱的采集；Capsule / Peek 保留原来的 8 根条与位置 |
| R07 首页吞关闭请求 | Quit / OpenSettings 宿主事件在页面指针路由前处理 |
| R08 文件夹超时 | 三个目录互相隔离；同一目录最多一个底层 OS 读取，重复点击复用，不在超时后无限堆积 worker；取消只结束当前等待，迟到结果仍不能回填已关闭的弹层 |
| R09 插件阻塞 UI | 包解压和目录事务转工作线程；第三方构造、初始化、生命周期、命令、场景回调的同步前缀不再在 UI 调用链执行；超时任务撤销贡献并隔离，不在代码仍执行时强制卸载 |
| R10 插件更新失败 | 激活失败不再无条件删除旧包；能安全卸载时回退旧版本并重新启用；不能安全卸载时保留旧包、明确提示恢复；测试确认回退后的命令仍有效、原配置保留 |
| R11 错误处理再抛错 / 静默退出 | 统一安全写日志与临时目录 fallback，启动 / 设置失败给一次简明提示；单实例通知失败返回明确退出码，错误处理不再直接裸写文件 |
| R12 品牌资源、R13 正式版本与交付 | 依用户最新要求不在这轮做；保留当前图案，不接入新资源、不调整正式版号、不生成发布计划 |
| R14 新键盘焦点模式 | 属于新增交互能力，未在本轮扩大范围；现有 UIA 保留，没有把普通键盘导航说成已实现 |

设置只补了“上一项保存失败”的状态，便于退出时保护未保存更改；五类 IA、布局、主题与蓝色 accent 没有重改。没有改自绘组件的既定几何、封面或播放控制排列。

插件 SDK 补充线程说明，见 [docs/plugin-development.md](<D:/Believe_in_yourself/about AI/work about agents/共同工作区/GlassDesk/docs/plugin-development.md>)。进程内插件仍只适用于可信代码，后台调用与 timeout 不是安全沙箱，也不承诺能终止任意第三方自行创建的线程或系统调用。
