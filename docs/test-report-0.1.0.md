## 修复与可控对照

**DPI恢复：**规范尺寸保存为DIP，WM_DPICHANGED使用新DPI，设置/显示变化后补读当前显示器DPI。隐藏回归覆盖96/120/144/192及往返，真实144 DPI尺寸通过，没有继续改全局缩放。

**设置崩溃：**unpackaged发布遗漏了GlassDesk.pri、App.xbf。复制原发布目录后仅加入这两个文件，582个原文件哈希全部不变，设置首次显示、重开及退出通过。项目现在显式发布PRI与全部XAML编译文件，并检查资源缺失；干净obj/bin副本还验证了嵌套XAML相对路径和哈希。转储只证明相同XAML失败路径，不能单凭HRESULT断定资源或Mica顺序。见 [App接口](app-api.md) 和 [上游发布缺陷](https://github.com/microsoft/WindowsAppSDK/issues/6720)。

**拖动终点：**Up原来只提交最后Move的位置，现与Move共用完整位移计算，用释放坐标补齐终点；缺失Move时，超过6 DIP的位移也不会误判为点击。两项回归先在旧代码失败，修复后32项通过。失败断言改为输出错误并返回非零退出码，避免未捕获异常的Windows错误框。

其他修复包括桌面不支持的HighContrastChanged事件订阅、过强颗粒及图形/异步媒体错误处理。硬件TDR、实际60FPS呈现、Explorer重启、真实睡眠唤醒、拔屏和系统高对比度/透明/节能开关变更尚未实测；不把资源重建、16ms计时或逻辑检查写成这些项目的实机通过。独占全屏游戏不属于首版覆盖承诺。

当前记录在artifacts/qa、artifacts/p0和artifacts/native/Release；源包排除桌面截图、运行配置和转储。完整分类见 [能力矩阵](capability-matrix.md)，普通用户试用路径见 [操作说明](user-guide.md)。
