# GlassDesk 0.1.0 能力矩阵

本矩阵记录实现范围与已经取得的证据，更新日期 2026-10-14。实机为 Windows 11 25H2 / Build 26200.9550、x64、单屏 2560×1600、150%（144 DPI），网易云 3.1.41.205564。最低兼容目标 Build 22621 仅为配置声明；其他电脑、干净 Windows 和混合 DPI 验证由用户安排后续下载试用。

“实机通过”表示真实桌面输入或实际媒体读回；“逻辑回归通过”表示 Core / Platform 或隐藏原生 fixture 验证；“已实现、待验收”表示源码已有处理，尚无完整生产场景实测。P0 证据来自独立探针，它证明接口或宿主能力，不自动替代最终 App 的 GUI 验收。生产桌面记录也只证明列明的操作，不代表所有功能均已验收。[P0 原始记录](p0-capabilities.md) 保留其当时阶段描述；生产 GUI 的最新结论见 [测试报告](test-report.md)。
