# GlassDesk：Windows 玻璃音乐小组件首版计划

## 1. 产品目标、范围与参考结论

第一版做一个适合长期自用、也方便朋友安装试用的悬浮音乐小组件。以网易云音乐为首个场景，用“胶囊 → 悬停小展开 → 点击大展开”打磨自然、跟手、可随时打断的交互。

**已确认的范围**

- 主体采用 **C# + WinUI 3 + Composition**；必要的 Windows 窗口、背景采样和图形互操作单独适配。
- 一个组件实例、三种视觉形态，默认顶部居中，支持跨显示器拖动、自由摆放和轻量吸附。
- 首版适配网易云音乐的歌曲信息、封面、上一首、播放/暂停、下一首及可用的播放时间轴。
- 未连接有效网易云音乐会话时，显示真实本地时间、日期和星期；暂停播放时保留歌曲内容。
- 歌词、喜欢/收藏、完整月历、天气、系统状态、成长和陪伴角色进入后续路线。
- 提供设置、托盘、位置与偏好保存、全屏避让，以及常规安装和卸载流程。
- 快捷键默认未绑定；开机启动默认关闭。

**工程与平台默认值**

- 内部代号 `GlassDesk`，首版版本号 `0.1.0`；代号暂不作为正式品牌决策。
- Windows 11 x64，最低兼容目标为 22H2／Build 22621；首个实机验收环境为本机 25H2／Build 26200.9550。
- 在全新目录建立工程：  
  `D:\Believe_in_yourself\about AI\work about agents\codeX\codeX work\GlassDesk`
- 不导入、读取或复用工作区其他项目代码。本会话仅完成计划，尚未创建工程或实现功能。

## 2. 交互与视觉规格

### 三种形态

以下尺寸为 100% 缩放下的初始设计值，使用 DIP；高 DPI 按比例渲染。

| 形态 | 默认尺寸 | 内容与进入方式 | 收起规则 |
|---|---:|---|---|
| 胶囊 | 232 × 48 | 小封面或状态光点、歌曲简短信息；无音乐时显示时间。默认形态 | 悬停连续 350ms 进入小展开；点击主体直接进入大展开 |
| 小展开 | 360 × 132 | 64 DIP 封面、歌曲名、歌手、上一首／播放暂停／下一首 | 鼠标离开有效区域 450ms 后收回胶囊；返回区域取消收起 |
| 大展开 | 360 × 464 | 208 DIP 封面、歌曲信息、播放进度与时间、播放控制、关闭入口 | 保持到主动关闭；鼠标离开和点击其他应用不触发收起 |

补充规则：

- 点击封面、标题或面板空白主体进入大展开；操作按钮只执行各自功能，事件不得继续触发展开。
- 小展开、按钮、提示浮层之间的移动视为同一次交互，不产生反复收起。
- 在动画途中点击、返回悬停区域或关闭时，立即改变动画目标。
- 歌曲更新、封面加载和播放状态变化只更新内容，不主动展开组件。
- 无音乐时，小展开显示时间、日期、连接状态和“打开网易云音乐”；大展开显示清楚的连接说明。
- 不展示模拟歌曲、模拟播放进度或尚未接入的歌词、收藏按钮。
- 大卡片空间不足时限制高度，内容区滚动；关闭与播放控制始终可达。

### 系统场景与可见性

三种视觉形态和隐藏原因分别管理，避免系统事件破坏用户状态。

- 普通应用最大化时保留胶囊；**新切入最大化应用**时收回胶囊。随后仍允许悬停小展开、点击大展开。
- 游戏或视频进入全屏时自动隐藏；退出全屏后在原位置恢复胶囊。
- 全屏中按已绑定快捷键，临时显示胶囊；不抢键盘焦点、不自动展开，随后允许正常悬停和点击。
- 全屏中再次按快捷键，关闭此次临时显示。退出全屏后清除临时状态，恢复原有手动显示／隐藏规则。
- 普通场景中的快捷键用于显示／隐藏；唤出时从胶囊开始。
- 首版面向普通视频及无边框全屏；独占全屏游戏不采用注入或强制覆盖。
- 手动隐藏作为本次运行状态；重启默认回到胶囊，再应用当前全屏规则。
- 原生组件、阴影窗口及设置窗口不参与外部应用的全屏／最大化识别。

### 拖动、展开方向与多屏

- 默认胶囊顶边距显示器工作区顶部 **24 DIP**，水平居中。
- 非操作区域按下后移动超过 **6 DIP**，进入组件拖动，并取消此次点击。
- 组件位置与鼠标保持一对一跟随；拖动期间停止自动悬停计时。
- 控制按钮、进度条和关闭按钮具有独立命中区域；拖动进度条不移动组件。
- 距工作区边缘或水平中线 **12 DIP** 内显示轻量吸附提示，松手后确认；吸附收敛约 120ms。
- 展开优先保持胶囊锚点；靠近边缘时向屏幕内侧展开，收起回到原锚点。
- 保存显示器稳定标识、工作区内位置和胶囊锚点。显示器断开后迁回主显示器并限制在可见区域。
- 首版支持一个实例跨显示器移动，不做每屏复制。
- 虚拟桌面采用普通 Windows 窗口所属桌面行为，暂不做跨桌面固定。

### 视觉与动作

- 默认白色半透明磨砂玻璃，真实背景采样与 GPU 模糊；细微颗粒、柔和亮边及低对比阴影。
- 初始模糊量为 **20 DIP**；材质参数集中为统一 token，三种形态共用。
- 胶囊圆角为高度的一半；小展开与大展开使用约 24 DIP 圆角。
- 字体采用 Windows 系统字体；透明表面文字使用适合透明背景的抗锯齿方式。
- 不同桌面背景下验证文字可读性；调整透明度时同步维护内容区对比度。
- 播放时光点轻微舒展，暂停时安静收敛；靠近、按下与拖动有克制回应。状态动效不表示真实音频频谱。
- 拖动不加入位置滞后或惯性漂移；个性主要体现在高光、光点与细小形变。

初始动作参数：

| 动作 | 默认值 |
|---|---|
| 胶囊 → 小展开 | 220ms |
| 小展开 → 大展开 | 260ms |
| 胶囊 → 大展开 | 280ms |
| 收回胶囊 | 220ms |
| 按下反馈 | 约 80ms，轻微缩放 |
| 内容与封面切换 | 120–160ms 淡入淡出 |

统一 `MotionController` 保存当前呈现位置与运动状态，打断后从当前状态继续。动画期间保持输入可用，不等待动画结束才处理操作。

系统关闭透明效果、高对比度、节能或图形能力不足时，切换到可读的实色材质。遵循系统减少动画偏好，保留状态变化的清晰反馈。

## 3. 技术架构、接口与数据流

### 技术基线与职责

初始固定：

- .NET 10 LTS，SDK `10.0.401`。
- Windows App SDK `2.5.1` 稳定版，使用依赖锁定文件。[官方稳定版下载信息](https://learn.microsoft.com/en-us/windows/apps/windows-app-sdk/downloads)
- Windows SDK `10.0.26100.0`，最低支持版本声明为 Build 22621。
- 原生层使用 MSVC x64、C++/WinRT。

按职责分为：

| 子系统 | 职责 |
|---|---|
| Core／C# | 三态状态机、可见性、拖动与吸附规则、内容模型、偏好、可测试的动作控制 |
| App／C# + WinUI 3 | 设置、首次引导、托盘协调、小组件视觉树和内容布局 |
| Platform／C# | 网易云媒体适配、系统场景观察、快捷键、启动项及原生互操作封装 |
| Native／薄 C++ 层 | HWND、真实背景采样、图形互操作、形状与输入区域、阴影辅助窗口和必要 UIA 支持 |

原生层不保存音乐业务状态，也不决定展开规则、内容布局或玩法。

### 玻璃宿主与窗口

小组件采用 Win32 宿主与 **Windows.UI.Composition**；设置使用 WinUI 3 及其 **Microsoft.UI.Composition**。两套合成对象分别管理，不互相传递。

- 使用 `DWMWA_USE_HOSTBACKDROPBRUSH` 与 `CreateHostBackdropBrush` 采样窗口背后的实际内容，再组合模糊、白色染色和细微纹理。[官方 Host Backdrop 支持](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute)
- C# 维护视觉树、布局、材质参数和运动状态；原生层提供合成目标、效果及文字／图像表面的互操作。
- 主体使用与当前呈现形状匹配的窗口区域和视觉裁剪。
- 外部阴影由同一宿主管理的穿透辅助窗口绘制；位置、形态、可见性和销毁与主体同步。
- 原生窗口默认不激活、不进入任务栏和 Alt+Tab；设置窗口正常参与 Windows 窗口管理。
- 透明外缘与阴影不截获其他应用的点击。不能仅凭视觉透明判定穿透成立。[Windows 分层窗口命中规则](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features)
- 合成器操作集中在 UI 线程。后台加载图片后，以会话与内容版本校验结果，再提交视觉更新。
- 原生资源、COM 对象、回调和表面具有明确所有权；关闭设置不结束驻留程序，退出时统一释放。
- 图形设备失效时先切实色材质，再重建必要资源。

```text

  StartAsync

IWidgetHost

```

`MediaSnapshot` 至少包含：

- 会话标识、内容版本号及连接状态；
- 歌曲名、歌手、专辑、封面引用；
- 播放状态及可用播放速率；
- 可选时间轴；
- 上一首、播放暂停、下一首、跳转进度的能力标志。

数据流固定为：

**Windows 媒体会话 → 网易云适配器 → MediaSnapshot → 内容场景与 WidgetController → MotionController／Composition 视觉树。**

时钟后备场景与音乐场景共用宿主和状态机。后续信息组件沿用内容场景入口，首版不建立外部插件系统。

### 网易云音乐适配

本机已确认客户端版本为 **3.1.41.205564**；当前未运行，因此系统媒体能力尚未实测，必须在 P0 验证。

- 使用 `GlobalSystemMediaTransportControlsSessionManager` 枚举媒体会话。
- 在实测中记录网易云实际 `SourceAppUserModelId`，建立准确的来源匹配规则。
- 只读取、控制匹配的网易云会话。浏览器或其他播放器成为系统当前媒体源时，不切换控制目标。
- 事件驱动更新媒体属性、播放状态和时间轴；关闭、重启客户端后重新绑定。
- 播放控制依据能力标志启用；捕获 `false`、超时和会话失效，并通过后续媒体状态验证结果。
- 接口缺少歌词与喜欢／收藏能力，相关增强留待后续独立接入方案。[Windows 媒体会话接口](https://learn.microsoft.com/en-us/uwp/api/windows.media.control.globalsystemmediatransportcontrolssession)

进度规则：

- 只有有效时间轴才显示确定进度；缺失时显示明确的不可用状态。
- 播放中使用收到的时间轴与单调时钟推算当前位置；暂停时停止推算，休眠唤醒后重新同步。
- 大展开期间约每 250ms 更新进度视觉，时间文字每秒更新；胶囊状态不做进度刷新循环。
- 跳转能力可用时允许拖动：拖动期间预览，松手提交一次请求。
- 系统跳转使用 `TimeSpan.Ticks`，并限制到来源提供的可跳转范围。[跳转接口单位](https://learn.microsoft.com/en-us/uwp/api/windows.media.control.globalsystemmediatransportcontrolssession.trychangeplaybackpositionasync)
- 封面异步加载、最长边限制为 768px，内存缓存最近三个；换歌后丢弃旧版本返回结果。
- 缺失封面使用原创占位图；应用不携带歌曲封面作为安装资源。

### 设置、驻留与持久化

设置采用浅色 WinUI 3 界面和原生材质，统一按钮、滑块、焦点与动效；包含：

- **外观**：玻璃强度、透明程度、简化动画、恢复默认。
- **交互与位置**：悬停／离开延迟、全屏避让、位置重置。
- **启动与快捷键**：开机启动、显示／隐藏快捷键绑定和清除。
- **连接与关于**：网易云连接状态、能力说明、版本和诊断导出。

约定：

- 外观变化实时反馈到小组件；快捷键注册失败时说明占用并保留原绑定。
- 托盘提供显示／隐藏、设置、打开网易云、重置位置和退出。
- 使用单实例机制；再次启动打开设置。
- 用户点击“打开网易云”才启动客户端；启动组件不自动开始音乐播放。
- 数据存放于 `%LocalAppData%\GlassDesk`；配置带版本号并原子写入。
- 损坏配置保留备份，恢复默认并给出一次清晰提示。
- 默认诊断记录程序、系统、来源能力及错误信息，不记录歌曲历史或账号信息。
- 小组件暴露 UIA 名称、启用状态、按钮 Invoke 和进度 RangeValue；设置使用 WinUI 内置可访问性。

## 4. 实施顺序、协作与安装交付

### P0：先验证两个基础

完成最小技术验证：

1. 网易云正常播放时，检查来源标识、歌曲信息、封面、三个基础控制和时间轴。
2. 验证未激活窗口中的真实背景模糊、透明轮廓、跨进程点击穿透、多 DPI 及资源释放。
3. 验证 WinUI 3 常驻生命周期与原生宿主共同运行，关闭设置后组件继续工作。

交付能力矩阵与可运行的技术验证结果，再进入完整视觉集成。

没有有效网易云会话或基础播放控制不可用时，P0 不算通过。记录具体错误及客户端可能提供的系统媒体设置；需要额外接入方式时先重新确认适配范围，不改动客户端代码。

### P1：三态交互原型

实现三态状态机、统一动作控制、拖动吸附、阴影和输入区域。测试使用独立测试数据源；生产启动连接真实来源或时钟后备。

提供可操作原型，重点复核快速经过、反复悬停、动画中点击、拖动及收起是否连贯。

### P2：真实场景与长期驻留

接入网易云数据和控制，完成全屏规则、快捷键、托盘、设置、多屏恢复、持久化和故障恢复。

### P3：安装器与验收

采用 **Inno Setup 7.1.0 x64** 构建常规安装器。[官方版本与安装器能力](https://jrsoftware.org/isdl.php)

- 按当前用户安装，默认目录 `%LocalAppData%\Programs\GlassDesk`，无需管理员权限。
- 随包携带 .NET、Windows App SDK 及必要原生依赖。
- 发布为 unpackaged、自包含目录；关闭单文件发布与裁剪。[WinUI 自包含部署要求](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/self-contained-deploy/deploy-self-contained-apps)
- 提供开始菜单入口；桌面快捷方式由安装页选择。
- 首次启动提供简短操作引导；开机启动与快捷键都保持关闭。
- 覆盖升级先让自身程序保存状态并正常退出，保留用户配置。
- 卸载移除程序、快捷方式和启动项，默认保留用户配置。
- 原型默认未签名；试用报告记录测试机实际出现的系统提示。证书购买与公开发布另行确定。

交付物：完整源码与依赖锁定、安装程序及 SHA-256、构建说明、操作说明、架构与状态规格、兼容能力矩阵和测试报告。

### 子智能体分工

后续执行会话允许使用子智能体。P0 和接口确定后，可并行分为：

- 原生宿主、材质、输入区域和资源生命周期；
- C# 视觉场景、动作控制和 WinUI 设置；
- 网易云适配、异步数据与能力测试。

主智能体负责状态规则、接口一致性、系统集成和最终验收。实际 GUI 验证集中执行，避免多个智能体同时操作同一窗口。

## 5. 测试与验收标准

**状态与操作**
