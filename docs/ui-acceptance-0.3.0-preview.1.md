## 视觉与交互实现

- 移除胶囊时钟、歌曲文字、大展开正文及时间轴文字的独立装饰底板；保留外层玻璃、封面裁切、圆形播放控件和陪伴导航。小展开时间相对整卡居中；大展开没有时钟、设置按钮或“交互预览”文字。
- 始终一个陪伴。移动时绘制相连渐细尾部，身体收窄并向前偏移；到位150ms内回聚，随后280ms完成一次阻尼形变。尾部不复制眼睛、耳朵或角，完整轮廓保持在边框内并避让内容。小展开安全槽较窄，实拍尾部较短，不宣称存在跨越封面的长拖尾。
- 原生、宽根猫耳和弯曲恶魔角共用身体变换。实际场景取消躲藏入口。胶囊角色32DIP；展开随机选择可达位置，每个位置的基准尺寸固定。
- 整个大展开导航是唯一陪伴身体，进入即弹性展开，离开保持；当前项居中、两侧渐隐、左右同圆角。五项仍为视觉选择预览，音乐正文保持，专注和随记业务页未在此次实现。
- 播放按钮94%按压反馈及260ms播放／暂停矢量切换。上一首、下一首立即发命令，再由真实内容变化驱动相反方向的封面300ms和文字280ms动画；减少动态效果时关闭非必要动作。
- 正文为实心深浅文字，没有文字描边或底板。布局、前景窗口或恢复事件后，220ms防抖进行四点背景取样。材质仍为WGC worker→GPU ROI→HLSL→Composition，不做持续CPU图像读回。同一前景窗口仅更换背景颜色时不保证立即触发文字取样，本次背景矩阵通过重新展开触发布局取样。

## 当前批次实机结果

证据位于`artifacts/qa/ui-0.3.0-preview.1/`，使用Cua Driver操作本机150%缩放桌面。旧候选的截图、短驻留不合并为当前通过结论。

液态玻璃三背景实拍：`resume-glass-{dark,light,complex}-unoccluded.png`及对应卡片裁切。复杂背景透出色块并在边缘模糊／折射；浅、深背景分别为深、浅实心文字。临时移开的遮挡窗口已按原位置和尺寸恢复并读回。`resume-glass-visual-summary.json`确认三图在5秒受控租约内保存；随后读回body=17、shadow=17，重启worker且保持用户启用偏好。普通实例另有`resume-ordinary-liquid-affinity.json`确认属性17、DPI144和PerMonitorV2。单窗口GWS可能遗漏系统Backdrop，不能以其占位背景判断视觉。
实际呈现探针`resume-native-presentation-stress.json`在25秒内采到100个运动间隔：P50约5.60ms，P95约13.70ms，最长30.28ms，2个超过25ms、0个超过33.4ms。探针位于三态压力期间，ROI与背景变化，并有418个未逐帧获取的桌面帧；它测量桌面像素变化间隔，不是应用Present时间或完整60FPS通过证明。

## 驻留与资源

前轮核心PID5948的记录因会话中断停在3511.53秒，扣除预热后仅3198.79秒；不计为一小时，也不与后轮拼接。前轮液态PID480的独立资源段扣除预热后为877.19秒，保留作短观察。
本轮普通核心PID2320与普通液态PID34864均无应用QA参数，设置关闭后进行真实网易云播放，独立读回音频Capturing。实际播放预热到22:35后，核心仅记录1001.36秒，液态仅记录1002.85秒，未完成一小时。约22:47至22:51黑屏保护覆盖桌面，核心按全屏避让隐藏，Esc退出后恢复；WTS仍为已解锁，故不误记为锁屏。两者最长采样连续可见约12分钟。接近用户额度暂停线时停止观察并恢复真实媒体暂停。
短观察中核心私有内存88.05→88.77MiB、峰值92.86MiB；液态宿主182.82→186.96MiB，拟合趋势+0.252MiB/min，仍需更长观察。全段解锁样本归一化平均CPU分别0.250%和0.369%，其中含黑屏遮挡，不能当成持续可见正常播放一小时结论。并行实例对比不是严格单实例A/B增量。完整原始数据和GPU进程计时见`current-residency-summary.json`；不将这几段短记录拼接成通过。
GPU原始计数按进程和引擎单独记录。本机元数据CounterType=542180608，使用累计差值和Timestamp_Sys100NS计算100ns活动时间，依据[Microsoft计时器计数类型](https://learn.microsoft.com/en-us/windows/win32/wmisdk/timer-algorithm-counter-types)。DWM属于全桌面合成，其值仅为环境记录；跨进程共享显存不直接相加为独占物理显存。
