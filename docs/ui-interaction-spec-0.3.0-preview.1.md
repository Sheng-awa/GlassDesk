# 0.3.0-preview.1 实现规格（2026-10-17 修订）

最新用户要求优先于旧计划。取消封面、导航后的躲藏和点击揭示入口；Core 旧类型保留用于兼容，实际场景不再提供躲藏锚点。

本轮视觉：去掉胶囊时钟、歌曲文字、详情内容和时间轴时间的独立装饰底板，仅保留小展开时间底板。外层玻璃、封面裁切和圆形播放按钮保留。

陪伴移动使用同一个角色与一对眼睛。沿已校验路径绘制相连的渐细尾部，主身体沿移动方向明显收窄并向前偏移，露出相连的残留尾部；到位后150ms收拢尾部，再完成280ms单次阻尼形变并回圆。尾部不包含额外眼睛或皮肤实例。只改变复用的Composition几何与变换，不逐帧创建路径资源。缩放不超过原有安全外廓，尾部各段重新检查保护区域；捕获、隐藏和减少动态效果立即清除残留。小展开进入时尝试一次可达移动，窄边缘遍历候选而非固定次数抽样。

- 复用现有三态、设置保存、插件和 Windows Composition 架构。PluginApi.Version 仍为 1；新增 Devil 形式，未知 ID 回退原生。
- 收起时一个 32 DIP 角色，中心在 (40,26)，三种皮肤的完整轮廓纳入圆角边界安全检测。系统本地时间 HH:mm，时间／日期／星期分别保存开关。音乐播放时沿用音乐胶囊，暂停五秒后切回时间。
- 小展开时间在卡片完整宽度的中轴单独排版；封面、文字、控制和波浪各自有保护区域。角色沿安全路径活动并变形，完整外廓在卡片内。
- 大展开没有时钟、设置按钮或“交互预览”文字。整个顶部导航是唯一陪伴身体：进入大展开即从48×48圆球弹性展开至264×48，鼠标离开后保持完整导航，避免再次呈现封面上方的独立小球。左右端半径一致，眼睛居中，同色猫耳／弯角保留身份，不叠独立小球阴影。选中项沿最短环绕路径移到中轴，近邻条形渐隐；UIA保留真实名称和预览选择语义。
- 导航保持五项视觉预览，音乐正文继续存在；专注、随记等业务页不在此次范围内。展开弹簧220ms，重排弹簧280ms。离开只清除悬停强调，关闭整张详情卡片才结束导航。重定向保留速度，新打开周期清空旧速度。
- 三种皮肤共用32点可形变轮廓和眼睛：原生、宽根猫耳、向内收尖的弯曲恶魔角。颜色、形式分别保存；眼睛自动使用浅色或深色。胶囊外的视线来自现有 GetCursorPos 定时读取，跟随开关也控制导航视线，关闭即清除。
- 播放按钮按压至94%后回弹，播放／暂停图标通过匹配拓扑矢量路径平滑切换。上一首与下一首命令立即发送，分别记录 -1／+1 方向，随后真实媒体变化驱动封面轻转和位移、文字淡入位移。封面300ms、文字280ms；外部切歌没有可靠方向时淡入。系统或应用减少动态效果时关闭非必要动画。
- 真实材质保持 WGC worker → GPU ROI → HLSL → Composition，最高30Hz，不进行持续 CPU 图像回读。降低大片白色衬底，增强边缘折射并保留清透中心，复杂背景继续自适应。GlassExplorer 只作视觉参考，不引入 iOS 私有 API。
- 设置保持现有顶部分页、DesktopAcrylicController、两块原生窗口区域、RGB／十六进制取色及250ms防抖保存。实际展开范围外左／右／中键按下使卡片收起，原点击继续传递；拖动／时间轴捕获优先。
- 预览与正式0.2.0的实例、配置、系统集成隔离。显式 QA 截图租约最多5秒，暂停采集并由独立看门狗恢复 body/shadow 采集排除；普通启动没有截图文件轮询。

移除文字底板后，正文使用实心深色／浅色文字；外壳几何、前景窗口或恢复事件后进行一次220ms防抖的四点背景明暗取样。取样在外壳和阴影外，避免读取被采集排除的黑色占位；不缓存图像、不逐帧取样、不修改按钮自身深色图标或系统高对比颜色。

实际验收及未实测边界见 ui-acceptance-0.3.0-preview.1.md；本规格不代表全部实机项目已通过。
