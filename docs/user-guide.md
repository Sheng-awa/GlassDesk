# GlassDesk 0.1 使用说明

支持 Windows 11 22H2 / Build 22621 或更新版本，x64。安装包自带 .NET 与 Windows App SDK 运行依赖。

## 安装与退出

1. 从本仓库 [Releases](https://github.com/Sheng-awa/GlassDesk/releases/tag/v0.1.0) 下载 `GlassDesk-0.1.0-win-x64-setup.exe`，运行安装。
2. 默认安装到 `%LocalAppData%\Programs\GlassDesk`，无需管理员权限。可选创建桌面快捷方式。
3. 安装结束后启动，或从开始菜单搜索 GlassDesk。首次启动会打开设置。
4. 关闭设置窗口后，组件继续在任务栏右下角托盘运行；完全退出请使用托盘菜单“退出”，或设置 → 通用中的退出操作。

安装包尚未代码签名。遇到 Windows 提示时先确认来源并核对发布页 SHA-256，不要关闭系统防护。干净 Windows 虚拟机安装与卸载测试仍未完成。

## 组件操作

- 悬停胶囊：查看小展开；音乐连接时保留封面、歌曲和播放控制，顶部陪伴球右侧显示时间。
- 点击主体相应空白区域：进入大展开。播放按钮只控制音乐。
- 点击大展开范围外：收起为胶囊。没有右上角收起按钮。
- 拖动空白区域：移动组件。显示 / 隐藏、找回位置和打开设置可以使用托盘菜单。
- 大展开默认进入音乐页，之后记住上次选择的实际页面。首页入口仍处于早期体验，限制见 [已知问题](known-issues.md)。

## 音乐

在网易云音乐中启用 SMTC / 系统媒体控制并播放歌曲。连接失败时可在设置 → 通用重新连接。应用只读取准确匹配的网易云媒体来源，不会在启动时自动打开播放器或开始播放。

可用操作由来源决定：上一首、播放 / 暂停、下一首；没有有效时间轴或跳转能力时，不提供进度跳转。暂停约五秒后只将收起的胶囊切为时间，不强制改变已打开的音乐页。恢复播放后胶囊回到歌曲显示。

本版没有账号登录、歌单同步或收藏功能。

## 设置

当前为六个分类：**外观、时间、交互、陪伴、插件、通用**。更改自动保存。

- 外观：材质、透明度及动态相关选项。
- 时间：默认、书卷、几何、等宽四种数字字体；分别控制时间、日期和星期。数字字体同步到胶囊与音乐小展开。
- 交互：悬停 / 离开延迟、全屏自动隐藏与位置。
- 陪伴：形式、颜色与鼠标跟随等选项。
- 插件：本地兼容插件及相关启停；液态玻璃默认关闭。
- 通用：登录启动、显示 / 隐藏快捷键、媒体连接、诊断与退出。登录启动默认关闭，快捷键默认未绑定。

系统减少动态效果与应用简化动画设置会影响动画呈现。高对比度或环境不支持透明材质时使用可读的回退材质。

## 隐私、插件与诊断

音频波浪条默认开启，只处理可靠识别的网易云进程树输出，用于本地可视化；不采集麦克风、不保存音频。暂停、隐藏或波浪条不可见时停止。液态玻璃开启后会在本机采样显示器背景并增加资源消耗。

配置默认存放于 `%LocalAppData%\GlassDesk`，卸载默认保留。不要自行将配置版本号降级，应用会校验并规范化兼容配置；当前偏好结构版本为 4，与应用版本 0.1.0 是不同概念。

插件为进程内可信代码，拥有主程序权限。只导入可信的 `.glassdesk-plugin` 文件；无法可靠卸载的插件可能要求重启。当前没有在线插件市场。

诊断先保留有界内存记录，点击“导出诊断”后写入文件；包含系统、能力、错误类型与错误码，不包含歌曲历史或账号。公开提交前检查文件与截图中的个人信息。详见 [隐私说明](privacy.md)。

## 更新与卸载

更新前从托盘退出，再运行安装包。可以从 Windows“已安装的应用”卸载 GlassDesk；设置目录默认保留。

首次发布的第三方声明抬头误写为 0.2.0，实际应用版本为 0.1.0；该文档错误与其他限制见 [已知问题](known-issues.md)。
