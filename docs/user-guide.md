# GlassDesk 0.2.0 操作说明

需要 Windows 11 x64，Build 22621 或更新。安装器随包携带运行依赖，安装到当前用户目录，不需要开发 SDK。

## 安装与第一次使用

1. 双击 `GlassDesk-0.2.0-win-x64-setup.exe`，阅读组件许可页后继续。默认安装目录为 `%LocalAppData%\Programs\GlassDesk`；桌面快捷方式可自行选择。
2. 安装完成后勾选“启动 GlassDesk”，或从开始菜单搜索 GlassDesk。首次设置页会显示操作引导；阅读后点击“知道了”。
3. 查看屏幕顶部居中的胶囊。未连接音乐时会显示当前时间；停留片刻可看日期和连接说明，点击主体可打开大卡片。
4. 正常打开网易云音乐并播放。若未连接，在网易云设置中检查 SMTC；开启该选项会将播放信息提供给 Windows 和能读取系统媒体会话的软件。
5. 关闭设置窗口后组件继续运行。再次启动 GlassDesk 会打开设置，不会创建第二个组件；需要完全退出时，在系统托盘菜单选择“退出 GlassDesk”。

## 操作与设置

启动后，小组件默认出现在屏幕顶部居中。鼠标停留 350ms 打开小卡片；点击封面、文字或空白主体打开大卡片。大卡片会保持打开，点击右上角关闭按钮收回胶囊。播放按钮只控制音乐，不会误触展开。

按住主体空白拖动可以移动位置；按钮和进度条有自己的操作区域。松手后靠近屏幕边缘或中线的位置会轻量吸附。托盘菜单可以显示／隐藏、打开设置、打开网易云、重置位置或退出。

GlassDesk 只读取和控制 Windows 系统媒体会话中准确匹配的网易云来源 `cloudmusic.exe`。网易云需要提供 SMTC 会话；如果没有连接，组件显示真实本地时间。设置中会说明当前连接与能力。启动 GlassDesk 不会自动打开播放器或开始播放。

如果客户端未提供时间轴，大卡片会隐藏进度条，设置中说明当前能力；不会编造进度。具备有效时间轴和跳转能力时，拖动进度条只预览位置，松手后提交一次请求。暂停达到五秒后，胶囊显示时间；已打开的小卡片或详情仍保留歌曲、封面和可用控制。恢复播放后胶囊立即显示歌曲。

设置使用“外观／交互／陪伴／插件／通用”五个标签，可调节玻璃强度、透明度、动画、悬停延迟和真实音频波浪条。波浪条默认开启，只采集已可靠识别的网易云进程树输出；采集不可用时归零，不使用其他程序的声音。暂停、隐藏及波浪条不可见时停止采集，不采集麦克风或保存音频。

开机启动默认关闭，快捷键默认未绑定。绑定失败时会说明占用，并保留原绑定。组件会避让普通视频和无边框全屏；全屏中使用已绑定快捷键可临时显示胶囊，再按一次隐藏。退出全屏后恢复此前的手动显示／隐藏状态。

时间使用系统本地时间，可在“外观”页分别开关时间、日期与星期。音乐小展开的时间居中，大展开保留封面、歌曲与控制。播放按钮有轻微按压回弹，播放／暂停图标平滑变形；系统减少动态效果或应用简化动画开启时直接切换。

陪伴球默认开启，始终只显示一个。每次展开随机选择不同位置，每个位置绑定固定大小；球体留在卡片内部。它会回应播放、切歌和触碰，并不定时眨眼；在“陪伴”页可改变颜色、关闭胶囊外的鼠标跟随。表情由原创矢量绘制。液态玻璃默认关闭，在“插件”页独立启用。启用后真实采样当前显示器背景，磨砂中心与更清透的弧面边缘呈现折射、细反光；文字和封面保持清晰。开启时组件可能不出现在外部截图或录屏中；关闭后恢复采集属性。显示器采集会增加资源消耗，默认保持关闭。环境不支持或采集失败时回退基础磨砂，并在设置中显示原因，用户开关仍保持启用。

“插件”页支持导入本地 `.glassdesk-plugin` 文件、独立启停、更新和移除。详情页的工具入口可打开插件内容页与操作。插件配置随同一标识更新保留；涉及原生组件或不能可靠卸载的插件会提示重启。只导入可信插件：它们在主进程中运行，拥有主程序权限。主程序没有插件市场或在线下载服务。

高对比度、关闭透明效果或节能时会采用可读的实色材质。组件遵循当前 Windows 显示缩放，不会自行更改系统缩放或其他系统设置。

## 更新、卸载与诊断

双击新版本安装器可覆盖安装；安装器会请求程序保存并退出。卸载可从 Windows“已安装的应用”找到 GlassDesk，或运行安装目录中的卸载程序。卸载默认保留偏好，方便重新安装。

配置存放在 `%LocalAppData%\GlassDesk\settings.json`。0.1 配置自动迁移为版本 2，保留位置、延迟、快捷键、启动项和已有外观偏好。首次安装及旧版升级新增波浪条和陪伴球默认开启、液态玻璃默认关闭。插件包与各插件配置分别放在 `plugins` 和 `plugin-config` 子目录。损坏的配置会保留备份，并恢复默认。在设置的“通用”页点击“导出诊断”，页面会显示导出文件路径；诊断只含系统、能力和错误信息，不含歌曲历史或账号信息。
