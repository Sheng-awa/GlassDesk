2 · 小组件入口：把右上角圆按钮拿掉

你发的参考图是“深色丝带 + 白色名字牌”。圆按钮设计本身不差，但放在角落破坏对称，也没有必要。

方案 A 推荐

音乐小组件

丝带不动，下面加一块小白牌：音乐 │ 小组件，点哪边切哪页；鼠标悬停其它槽时，白牌临时显示槽名 +“预览”。

没有新按钮、左右对称、有常驻文字、陪伴球不用另找地方。

方案 B（最接近你的参考图）

音乐

当前槽展开成白色名字牌（LINK 1 的样子），左边眼睛、右边名字；其余槽保持小条。

名牌会盖住相邻槽；5 个槽里没有“小组件”，切页逻辑要再定；动画更复杂。

方案 C（最彻底）

音乐

把“小组件”做成五个槽之一（音乐、小组件 + 3 个预览），每个槽都有名字牌，不要单独入口。

信息最清楚，但改变五槽含义，需要你拍板。
