2.5 · 陪伴球：三种形态里各做一件事

你的定义是“一团围绕着你、会变形的液体”，不是 UI 里多一个球。胶囊形态你满意；小展开和大展开迷茫，是因为它变成了“边缘上的点”或“一根带眼睛的长条”，没事可做。

P1 · 举牌 推荐

胶囊里是球；小展开贴边探进来；大展开变成名字牌（眼睛 + 当前页名），丝带回归纯导航。

它的任务：陪着你 → 贴边看你 → 举着你的当前页面。胶囊完全不动，液体有连续变化。

眼睛从丝带移到白牌上，需要你点头。

P2 · 丝带就是身体

眼睛留在丝带上，整条丝带就是液体拉长后的样子，白牌是它举着的。

最贴近你最初“藏进导航”的想法。

必须让长条真的像液体（端部鼓起、表面张力、切换时流动），否则永远像工具栏；难度最高。

P3 · 贴边液体

大展开里眼睛不进导航，而是趴在卡片边缘、偶尔沿边走；丝带纯导航。

最符合“围绕用户的液体”。

要新位置与新动画，可能挡内容，风险中。
