01怎么转译

原组件（真实结构，已取源码）

  • 236 左右的渐变圆角卡：radial-gradient(#ff89cc → #9cb8ec → #00ffee → #62c2fe)
  • 四个 .box（70%/50%/30%/10%）藏在左下角，hover 时依次滑入，各带自己的渐变和图标
  • 中心 logo 在 hover 时移到右下角；卡片整体 scale(1.1)

GlassDesk 版本

  • 四张「入口卡」= 时钟 / 音乐 / 小组件 / 文件夹（原来的 4 个 box 正好对应 4 个入口）
  • 入口卡尺寸 86/72/60/54，保证命中 ≥44 DIP；从卡片左下角向右上依次展开
  • 图标 only；名字只在 hover 时以小胶囊出现，UIA 名称完整
  • 中心 logo（陪伴的两只眼睛）在展开时移到右下角

02视觉规格（收敛版）

项值说明
导航卡236×236，圆角 40，radial 渐变唯一彩色焦点，其余页面保持深色玻璃
入口卡86 / 72 / 60 / 54，圆角 24，左上白边大→小叠放，每张一个色系
动效0.85s，cubic-bezier(.34,1.16,.4,1)，每张延迟 80ms展开从下往上依次落位；收起反向
文字只有 hover 胶囊 + 时钟/日期没有副标题、没有说明文字
命中入口卡整块可点，最小边 54>44键盘 Tab / Enter / UIA Invoke
降级减少动态：无位移，直接显隐跟随系统设置

03技术落地（自绘管线）

可以做到

  • 渐变卡：预烘焙一张 PNG 当 SurfaceOp.Image 贴图（不用改 native，也能得到真 radial 渐变）
  • 展开/收起：Composition offset + opacity 逐张延迟动画；图标用现有 Icon 原语
  • 文件夹入口：Platform 增加 OpenExplorer()，ShellExecute “explorer.exe”；失败走当前页错误条

近似与边界

  • 卡片缩放/白边浮雕可用 1px 半透明描边近似，不做真 blur
  • 渐变卡的边缘高光如果 PNG 烘焙不好，会退化为纯色 + 顶部高光线（需在真机校验）
  • 首版只做 4 个入口；专注/随记暂不出现（等真实页面再用同一张卡扩展）
