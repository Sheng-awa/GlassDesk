状态 A：导航页固定 4×4；状态 B：点击 Dock 文件夹，Dock 上方弹出内容气泡，点条目打开资源管理器。

01布局与交互

区块规则
导航页（上方）massive-insect-5 的玻璃卡 + 眼睛；内部固定 4 列 × 4 行（一行最多 4 个应用，共 16 个位置）；应用位 hover 上移 + 6% 白底，点击进入
应用位图标 34×34、圆角 11；名称 9px；空位虚线占位，最多 16 个
眼睛无瞳孔，两只白眼睛整体轻微跟随鼠标（≤2 DIP）；放在导航卡右上角
Dock（底部）只放文件夹（可配置 3–4 个，设置里指定路径）；hover 轻微放大；右侧分隔线 + 眼睛
文件夹气泡点击 Dock 文件夹，在 Dock 上方弹出（方向/位置对齐该文件夹）：标题 + 内容预览（最多 4 项）+「在文件中打开」；再次点击关闭；点击条目打开资源管理器

02动效

项规则
导航页应用hover 上移 1 DIP + 6% 白背景；点击切换页面（无展开动画，固定 4×4）
Dock 文件夹hover 上移 4 DIP + 放大 1.12，0.12s 弹性
文件夹气泡从 0.94 / +6 DIP / 透明 → 1，0.26s 弹出；关闭反向；箭头指向点击的文件夹
眼睛无瞳孔；整体朝鼠标偏移 ≤2 DIP，10ms 缓动
减少动态位移/缩放直接完成，只保留透明度

03统一圆角

元素圆角说明
窗口24最外层
导航页卡 / 文件夹气泡22 / 20大卡片层级
Dock20与气泡同层
应用图标 / Dock 图标 / 气泡条目12内层
图标内圆角 / 小元素11 / 8递减阶梯

规则：外圆角 → 内圆角按 24 / 22 / 20 / 12 / 11 / 8 阶梯取，内层 ≈ 外层 − 内边距，避免“外方内圆”或反过来的割裂。

04技术落地（不改 native）

  • 导航页：固定 4×4 网格用 Core 布局常量，App 侧自绘图标/名称；应用位 hover 反馈
  • Dock 文件夹：设置里存 3–4 个路径（settings.json 新字段），启动时校验存在性；点击时枚举目录（最多 4 项）+ 读图标
  • 气泡：以文件夹图标为锚点，固定宽度 296，flip 到屏幕内；打开前只读目录，不写数据
  • 打开资源管理器：Platform 新增 OpenExplorer(path)（ShellExecute explorer.exe）

需要真机确认

  • 图标 34×34 / Dock 40×40 在 150% DPI 下清晰度；命中扩到 ≥44
  • 文件夹枚举的权限/路径不存在错误态（当前页错误条）
  • 导航页与 Dock 的层叠关系、气泡与 Dock 的遮挡
  • 真实文件图标（Shell 提取）与自绘 fallback 的视觉一致性
