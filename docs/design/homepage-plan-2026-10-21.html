02导航条改造

保留原组件的骨架

  • 渐变底 + 白色玻璃方块 + 白顶边 + 从左下角展开的延迟节奏（0.2 / 0.4 / 0.6s）

为长方形做的调整

  • 200×200 方卡 → 328×156 长条；box 从“左下角扇形叠放” → “底部横向依次滑出”
  • 4 个 box：3 个图标卡（音乐 / 小组件 / 专注）+ 1 个装饰小方块，保留原节奏
  • 眼睛：收起时居中；展开后移到右上角，瞳孔跟随鼠标（限制 2.5 DIP 位移）
  • 配色：磨砂玻璃渐变（冷白/灰蓝），替换原粉青；文件夹保留琥珀色

04技术落地（不改 native）

  • 玻璃渐变：预烘焙 PNG（含 alpha）当 SurfaceOp.Image；白边/阴影用现有圆角矩形 + 半透明线
  • 导航条/图标卡展开：Composition offset + opacity，逐张延迟；眼睛跟手可用现有 companion 指针位置
  • 文件夹 3D：纸片上升 + 前盖下移 + 内阴影近似；点击走 Platform 新增 OpenExplorer()

需要真机确认

  • 磨砂 PNG 在 Composition 上的色偏与暗色底表现
  • 328×156 长条 + 154×156 上排卡在 360×512 的比例
  • 眼睛在 15×21 尺寸下的可视度/跟随幅度
  • 图标卡命中 76×76 ≥44；文件夹卡整块可点
