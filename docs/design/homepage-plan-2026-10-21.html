01结构照抄，只换颜色和图标

导航卡（原结构）

  • 200×200、圆角 30、overflow:hidden、hover scale(1.1)
  • 4 个 box：70% / 50% / 30% / 10%，藏在左下角（-70%…-10%）
  • hover 时全部滑到 bottom:-1px;left:-1px，延迟 0.2/0.4/0.6s 依次落位
  • 白边玻璃方块（rgba(255,255,255,.389) + 2px 白顶边），logo 从中心移到右下

改了什么

  • 背景：粉青 radial → 磨砂玻璃渐变（冷白→灰蓝，低饱和、半透明）
  • box 的 hover 渐变：彩色 → 玻璃冷光；仍保留原白边/阴影
  • 图标：相机/Twitter/Discord → 时钟 / 音乐 / 小组件；box4 留空
  • logo：原 “UI” 标 → 陪伴的两只眼睛（你说这个效果可以）

03技术落地（不改 native）

  • 导航卡的磨砂渐变：预烘焙 PNG（含 alpha）当 SurfaceOp.Image 贴图；box 的白边/阴影用现有圆角矩形 + 半透明描边
  • 展开：Composition offset 动画，逐张延迟 0.2/0.4/0.6s；logo 移动用 offset 动画
  • 文件夹 3D：用「纸片上升 + 前盖下移 + 内阴影」近似（没有 rotateX）；或也预烘焙两帧图交叉淡入
  • 点击文件夹：Platform 加 OpenExplorer()（ShellExecute explorer.exe），失败走当前页错误条

需要真机确认

  • 磨砂渐变贴图在 WinUI Composition 上的色彩和暗色底是否接近本页
  • 200×200 卡片 + 142 文件夹在 360×512 里的比例（本页按此比例做）
  • hover 展开在 1s 内完成，减少动态时直接显隐
  • 入口命中：box1/2/3 均有 60–140 DIP，折叠时不可点隐藏区域
