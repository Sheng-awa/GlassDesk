首页改版：把「导航栏」拆成一组卡片

首页 = 大展开的第一页。取消底部 Dock，用一组可点的卡片承担导航（时钟、音乐、小组件…），再放一个琥珀色 3D 文件夹卡作为「打开资源管理器」入口。本页是给 GPT 审查的设计稿 + 可交互视觉模拟，不是最终实现。

版本 v0.1 日期 2026-10-21 设计/技术 DeepSeek 审美审查 GPT（待） 目标构建 0.3.0-preview.4

一页结论（TL;DR）

  1. 首页成为唯一导航：去掉 320×48 的底部 Dock；从任意页点顶部陪伴把手回首页。
  2. 导航 = 2×3 卡片网格：时钟 / 音乐 / 小组件 / 文件夹 / 专注 / 随记；图标 + 标题 + 一行说明，全部 ≥44 DIP 命中。
  3. 文件夹 = 3D 琥珀文件夹卡：hover 时前盖打开、纸片升起（参考 Uiverse / Cobp），点击打开资源管理器（默认“此电脑”，后续可配置路径）。
  4. 视觉语言：深色玻璃 + 单色微光边，卡片按用途着色（青/蓝/紫/琥珀/粉），发光只做“呼吸”，不做霓虹。
  5. 先做静态首页再谈动效：本页通过审查后，用现有 Core/App 自绘管线落地，不需要改 native。

01为什么是「卡片网格」而不是 Dock

Dock 的问题

  • 320×48 只放得下图标，没有文字，新用户要记忆；
  • 只能横向放 5 项，加「文件夹」就会挤；
  • 「首页」概念缺失：现在点胶囊直接落音乐页，没有“家”。

卡片网格的好处

  • 2×3 六张卡能自然容纳图标 + 名称 + 一行说明；
  • 每张卡就是一个页面/动作，导航与功能合一；
  • 文件夹卡可以做得像“物件”（3D 文件夹），比 Dock 图标更有记忆点；
  • 后续加卡不需要改布局骨架，只加卡片。
取舍：去掉 Dock 后，跨页跳转必须回首页。建议只有首页有网格；其他页面保留「顶部把手 = 回首页」，不再放底部导航。若你希望保留快速切换，可在首页之外加一个很细的 4 DIP“进度点”，但不放可点 Dock。

02参考组件转译（含源码依据）

两个 Uiverse 组件都是 MIT 许可。下面说明「拿到了什么、怎么改造成 GlassDesk」。注意：Uiverse 页面是客户端渲染 + 站点有反爬，普通搜索/抓取只拿得到标签。文件夹卡的源码已通过一次浏览器 DOM 转储取到（原样保存为 artifacts/qa/ui-home/mighty-pig-13.source.html）；导航卡的源码没取到，按标签（rounded / gradient / glow / centered / label）转译，标为假设，供审查纠偏。

① 文件夹卡 · Cobp / mighty-pig-13

MITTailwindfolder / hover / instruction

真实结构：5 层 div 叠出「3D 文件夹」——后壳 + 3 张纸 + 前盖；hover 时纸片分别 rotateX(-20°/−30°/−38°)，前盖 rotateX(-46°) 打开，底下一行低透明度 “Hover over” 提示。

转译到 GlassDesk：琥珀色保留；纸张层用 3 条圆角矩形；前盖打开用「前盖下移 + 纸片上移 + 顶部内阴影」近似（自绘管线没有 3D 变换）。提示文字改为「打开资源管理器」。

② 导航卡 · Smit-Prajapati / massive-insect-5

MITCSSgradient / glow / rounded / centered / label

标签显示：圆角、渐变（蓝/粉/青）、发光、居中标签、hover 动效的卡片。具体 CSS 未取到，因此这是假设的转译：把原来的“大发光卡”压成导航卡：玻璃底 + 顶部一束同色微光 + 1px 发光下边线；hover 上浮 2 DIP、光晕变亮。

需要 GPT 重点审查：这种发光强度会不会太“网感”，和 GlassDesk 的安静玻璃气质冲突？备选：完全去掉光，只用单色下边线。

06技术落地（GlassDesk 现状约束）

能直接做

  • 新页面 home：DetailsPageController 加页；首页成为 Details 默认页；
  • 卡片几何：Core 加 HomeLayout（360 基准、2×3、响应式高度）；
  • 文件夹启动：Platform 加 OpenExplorer()（ShellExecute “explorer.exe”），错误走现有 notice/当前页错误条；
  • hover/press/动效：Composition offset/opacity 动画，减少动态联动；
  • 测试：Core 布局检查 + 现有 282 checks 全绿。

需要近似 / 明确限制

  • 渐变/发光：自绘 SurfaceOp 只有纯色圆角矩形；本稿的光晕用「叠层半透明 + 模糊宽度近似」，不做真 gradient/blur（要真效果需扩展 native，单独立项）；
  • 3D 文件夹：没有 rotateX；用「前盖下移 + 纸片上移 + 内阴影」近似，视觉保留“打开”感但不做透视；
  • 不在首页放 Dock：跨页返回依赖顶部把手；若后续要做手势返回，另行设计；
  • 文件夹路径首版固定“此电脑”，不做路径配置/拖拽（避免范围膨胀）。
