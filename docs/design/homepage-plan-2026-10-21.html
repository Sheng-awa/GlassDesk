01布局（按你最后一张手绘图）

区域结构
导航页（上方玻璃卡）顶部一行 4 个大小不一的格子；左下 2×2 小格；右侧一个大格跨两行（大格 = 时钟）。格子不必铺满整个区域，尺寸/间距按内容来。
应用位小格：图标 28×28 + 名称 8px；大格：时钟 09:41 + 日期，占 2 列 × 2 行
Dock（底部）只放文件夹（当前示例 crucial / 项目 / 下载，路径在设置里指定）；文件夹图标是 3D 文件夹的缩小版
文件夹气泡点击 Dock 文件夹 → 上方弹出内容（标题 + 3 个文件 + 在文件中打开）；点条目打开资源管理器；再次点击关闭

02文件夹动画（缩到 Dock 尺寸）

用你给的 mighty-pig-13 结构缩小

  • Dock 图标里是 34×24 的 5 层文件夹：后壳 + 3 张纸 + 前盖
  • hover：前盖 rotateX(-46°) 打开，纸片 -20/-30/-38° 依次升起，内阴影加深
  • 点击：在 Dock 上方弹出内容气泡（图 1 效果）

气泡再点一次

  • 点文件条目 → 在资源管理器中定位该文件；点「在文件中打开」→ 打开该文件夹
  • 气泡 0.26s：0.94 / +6 DIP / 透明 → 1；箭头指向 Dock 文件夹
  • Esc / 点击外部关闭；键盘 Tab 可顺序访问

04动效 / 鼠标跟随

项规则

05技术落地（不改 native）

  • 便当格：Core 里定义 4 列不等宽轨道 + 大格跨 2 行/2 列的矩形表；App 侧按矩形绘制
  • Dock 文件夹：设置里存 3–4 个路径（settings.json 新字段），启动校验；点击时枚举目录（最多 4 项）
  • 3D 文件夹：自绘管线用「前盖下移 + 纸片上升 + 顶部内阴影」近似 rotateX；尺寸 34×24
  • 气泡 / 打开资源管理器：Platform 加 OpenExplorer(path)（ShellExecute explorer.exe），只读目录

需要真机确认

  • 便当格不等宽在 360 DIP 下是否显得碎；大格 2×2 的比例
  • 34×24 文件夹在 44 命中区内放大后的清晰度
  • 文件夹枚举权限/路径不存在 → 当前页错误条
  • 气泡与 Dock、导航卡底部的层叠关系
