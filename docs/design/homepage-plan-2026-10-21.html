项目：GlassDesk，一个 Windows 桌面陪伴应用（WinUI 3 + 自绘 Composition UI，非网页/非 XAML）。

本次任务：重做「首页」= 大展开后的第一页。

用户明确要求：

  • 右下角大卡片是导航页，用 massive-insect-5 那个组件（玻璃卡 + 眼睛 + hover 展开的 4 个格子）；不是时钟。
  • 其余是常用应用图标：统一大小、无外框、可以留空、不要求占满；按 4 列 × 3 行排列。
  • 底部 Dock 只放文件夹；文件夹用之前给的 3D 文件夹动画缩小；点击展开文件夹内容气泡（如图 1），再点打开资源管理器。
  • 动画要有；圆角要统一；不要一层又一层的框。

请 GPT 重点审：层级与比例是否清楚、留白是否舒服、应用图标与导航卡是否抢、Dock/气泡是否像 macOS、圆角/间距/字体是否统一，以及一张截图里最刺眼的一处。

01布局

区域说明
应用图标（左上区域）8 个示例应用，4 列 × 3 行网格；图标统一 52×52、标签 9.5px、无外框；行高 96、列距 12、行距 14；空位可以留空（不要求占满）
导航页（右下角大卡）占网格右下 2×2 格（约 156×206）：massive-insect-5 收起只剩眼睛；hover 时 4 个格子（70/50/30/10%，延迟 0.2/0.4/0.6s）滑入左下角，眼睛移到右下角，卡片放大 1.06；3 个图标 = 音乐 / 小组件 / 时钟，第 4 个留空装饰
Dock（底部）只放文件夹（示例 crucial / 项目 / 下载，路径在设置里指定）；文件夹是 34×24 的 5 层 3D 文件夹缩小版
文件夹气泡点击 Dock 文件夹 → 上方弹出：标题 + 最多 3 个文件预览 + 「在文件中打开」；再点关闭；点条目打开资源管理器

02格式统一

只有三层容器有“框”

  • 导航卡（约 156×206，占右下 2×2 格，圆角 26）
  • Dock（320×56，圆角 20）
  • 文件夹气泡（296×166，圆角 20）
  • 其余（应用图标、气泡条目、导航格）都是无边框的填充面/图标，不再套框

统一规则

  • 图标 52×52，圆角 14；标签 9.5px、颜色 #A8B3C2
  • 应用网格：4 列 × 3 行，行高 96、列距 12、行距 14；不强行铺满
  • 圆角阶梯：24 / 26 / 20 / 14 / 12 / 5
  • 间距只用 4 的倍数（8/12/16/18/24）

03动效

项规则
导航卡 hover4 个格子 0.9s 滑入（70/50/30/10%，延迟 0.2/0.4/0.6s）；眼睛移到右下；卡片 scale 1.06
应用图标 hover上移 2 + 放大 1.04，0.16s
Dock 文件夹 hover整块上移 3 + 放大 1.08，同时 3D 文件夹打开（前盖 -46°，纸片 -20/-30/-38°，0.3s）
文件夹气泡0.26s：0.94 / +6 DIP / 透明 → 1；箭头指向文件夹；关闭反向
眼睛无瞳孔，两只整体跟随鼠标 ≤2 DIP
减少动态位移/缩放/旋转直接完成，只保留透明度

04技术 / 实施

  • 应用网格：Core 定义 4 列 × 3 行（行高 96、列距 12、行距 14），图标 52×52 + 标签；按实际数量排布，空位留空
  • 导航卡：Core 里占右下 2×2 格（约 156×206），自绘玻璃卡 + 4 个 70/50/30/10% 方块的 offset 动画；眼睛用现有 companion 指针位置
  • Dock 文件夹：设置里存 3 个路径（settings.json 新字段）；点击时枚举目录最多 3 项
  • 打开资源管理器：Platform 新增 OpenExplorer(path)（ShellExecute explorer.exe）
  • 不改 native；渐变/磨砂用预烘焙 PNG 或半透明叠加近似

阶段

  • P1：首页 360×512，应用图标网格 + 右下导航卡 + 底部 Dock（占位路径）
  • P2：Dock 文件夹 3D 动画、设置路径、内容气泡、打开资源管理器
  • P3：眼睛跟随、hover 反馈、键盘/UIA、减少动态、截图与测试
