## 1. 最终方向

**固定侧栏 + 单列设置行 + 稳定右侧控件 + 独立的小型效果预览。**

重点是建立阅读与操作秩序。整体保持浅色、蓝色 accent；通过字号、墨色、留白和材料分工建立层次。设置正文以平整、稳定、清晰为主，玻璃只服务于少量预览和侧栏背景，不让正文跟随桌面壁纸变灰。

保留的五类及顺序：

| 稳定 ID | 显示名称 | 内容 |
|---|---|---|
| appearance | 外观 | 组件模糊/透明度、时间日期星期、简化动画、音频波浪条、恢复默认外观 |
| interaction | 交互 | 悬停/离开延迟、全屏隐藏、位置重置 |
| companion | 陪伴 | 启用、视线跟随、现有三种形式、颜色与预览 |
| plugins | 插件 | 液态玻璃、本地插件导入、运行状态、配置贡献与工具操作 |
| general | 通用 | 自启动、快捷键、音乐连接、诊断、版本、退出 |

不加入 BrimDeck 的额度、账户、模型价格、多播放器或联网更新功能；它们不是本轮设置设计需求。也不新增深色主题、设置搜索、天气或插件市场。

陪伴页的黑色角色是现有互动角色的预览，**不是把应用 Logo 重新改成黑胶囊**。已设计的品牌 S 图案不在本轮重画。

## 3. 当前 GlassDesk 的代码证据与改版原因

| 当前代码 | 已确认的结构 | 新方案解决什么 |
|---|---|---|
| SettingsWindow.cs / BuildContent | 根布局第一行是浮动标签，第二行是独立圆角面板；标题、页身、页脚分层 | 合并为一个连续窗口，减少“导航漂在外面、内容另起一块”的结构分裂 |
| SettingsFloatingNavigation.cs | 顶部共享胶囊，支持拖动与弹簧位置，ProgressChanged 连续推页面位置 | 设置改为点击选择；鼠标经过仅 hover，不切页。避免在高频设置中把运动当主要视觉 |
| SettingsPageDeck.cs | 五个 ScrollViewer 均参与布局，用 Progress 计算横向 TranslateTransform | 新切页不再驱动五整页横移；保留各页滚动位置和即时响应 |
| SettingsColumns.cs | 612 DIP 及以上采用两列，固定将不同内容卡片配成行 | 普通设置改成单列，标题与控件连续对齐；仅形式选择等同类选项保留横排 |
| SettingsWindow.cs / Group / Surface / SliderRow | 多个带填充、边框和圆角的卡片，滑块独占块布局 | 相同设置合并为组，组内轻分隔；不要每个开关再包卡片 |
| SettingsWindowShape.cs | 两个 HRGN 区域相并，保留标签与面板间的桌面空隙，并修改原生窗口样式 | 侧栏版不再需要双区域窗口；必须同时退役旧遮罩和无边框样式，不能只换 XAML |
| SettingsAcrylicBackdrop.cs | 设置固定浅色 Acrylic，TintOpacityValue=.86，不跟随组件透明度 | 保留这种职责分离，正文使用稳定底色；本轮不接管组件液态玻璃管线 |
| SettingsTypography.cs | 已有系统 A 字体回退、CJK/Latin run、tabular 数字处理 | 继续使用，避免新设计又引入另一套字体与中文伪粗体 |
| SettingsWindow.cs / FlushPreferencesAsync | 250 ms 合并保存、pending/in-flight、RebasePending 和外观预览代次保护 | 全部保留；视觉重做不能把正确的写入合并、位置合并和异常处理一起丢掉 |

这些是设计改造依据，**不表示所有旧布局都是 bug**。本轮方案是用户发起的新方向，不应伪装成只改几个颜色就能完成的小修。

## 4. 布局与视觉 Token

数值为本方案目标，单位为 DIP；HTML 在 100% 缩放时用 CSS px 近似。

### 窗口与排版

| 普通设置名 | 14 / 20–21，400 |
| 分组名 | 12 / 18，400，用墨色和留白区别于设置名 |
| 描述 | 12 / 18，400，最多必要的一到两行 |
| 侧栏标签 | 13–14 / 20，常规和选中不依赖中文伪粗体区别 |

纯色 sRGB 对比计算结果：

| 组合 | 比值 |
|---|---:|
| 主墨 / 正文画布 | 15.03:1 |
| 次墨 / 正文画布 | 6.32:1 |
| 辅助墨 / 侧栏 | 4.85:1 |

### 深度的来源与禁止项

让内容前后有别，靠稳定画布、清楚字阶、控件压下/悬停反馈和少量预览材料层。文字本身不加内阴影、描边、光晕或浮雕。

不使用：中文加字距、多重软阴影、全页透背景、每行卡片、持续漂浮、每个按钮弹簧、无文字侧栏、只靠颜色表达错误。不要打包新字体；系统 A 不变。

## 5. 各页的具体构成

### 外观

顺序：页标题/一句说明 → 小型材质示意 → 材质两行 → 时间胶囊三项 → 动态两行 → 恢复默认外观。

透明度必须维持现有方向：UI=76% 对应 TintOpacity=.24。公式仍为 UI=(1-TintOpacity)×100；区间 10–90。不要误将 76% 保存成 .76。

模糊范围 0–40；不擅自加“px”等未核实的单位。材质预览使用确定的示意背景，不建立 WGC 截屏或后台渲染循环。HTML 预览中的胶囊是材料示意，**不是新的胶囊尺寸/排版规范**。

时间/日期/星期保留三个独立字段与既有合法组合，不新增“至少一项”限制。恢复默认只恢复现有处理的字段，不顺手改音频、位置、插件或页面记忆。

### 交互

悬停与离开延迟各一行，沿用 100–1500 ms、步进 50。全屏隐藏单独一组。位置重置是次操作，不占据大卡片，也不新增监控器管理或 Dock 位置功能。

### 陪伴

顶部是有限尺寸的角色预览，作为此页视觉焦点。下方保持行为、形式、颜色三层；开启/跟随开关不分散到不同卡片。

形式沿用 Original / CatEar / Devil 对应的现有 ID，显示名仍是原生/猫娘/恶魔。SVG 仅是 HTML 示意；原生版复用现有角色路径，不能把示意耳朵当成新的角色资产覆盖。

颜色：紧凑预设 + HEX + 可展开的原生 ColorPicker。无需默认展开整块 RGB 大面板；ColorPicker 及通道仍必须可达。HEX 输入中间态不被 Refresh 改写，非法值就近提示，失焦/Enter 规则延续现有提交策略。

指针视线仅在预览区和本页可见时更新；遵守 CompanionFollowMouse、CompanionEnabled、ReducedMotion；离开恢复自然位置。无后台常驻眨眼计时器。

### 插件

液态玻璃是内置项；状态区解释“请求开启”和“实际运行”是否一致，包括未启用、运行、暂停、初始化失败/回退、需要重启。

本地插件保持平整列表和明确的导入入口。原型只演示一个简化流程，**生产不能删掉当前已有的插件设置贡献与 PluginPages 工具操作**。列表来自 coordinator，不写死示例插件。

完整状态至少包括：空、导入中、导入成功、包无效、重复更新失败已恢复、无法安全卸载需重启、禁用、运行、移除失败。失败原因应贴近对应插件；不把所有失败都缩成一个瞬间消失 toast。

导入和移除仍调用现有宿主；不运行下载代码，不引入市场或网络权限。进程内可信插件说明保留。

### 通用

启动与快捷键 → 音乐连接 → 关于与诊断。仅保留已有业务。

音乐状态分清未连接、连接中、已连接但无时间轴、错误；能力来自 MediaSnapshot，不能因为界面设计了进度条就假定播放器支持。重连期间按钮不可重复触发。

快捷键输入保留捕获冲突与失败提示；Escape 录制取消优先于窗口关闭。UI preview 中自启动和全局热键应继续按 IsUiPreview 禁用，**HTML 的可点击模拟不是取消这个隔离约束**。

关于保留真实构建版本、平台、诊断路径、已有隐私说明和退出。HTML 中“设计预览”不是将来正式版号。

## 6. 原生实现路线与文件边界

沿用 C# / WinUI 3；设置是 XAML UI，桌面组件是另一条 Composition 管线。**不迁移 WPF、不嵌入 WebView2、不把 HTML/CSS 当成生产渲染器。**

建议拆出这些设置专用组件：
- SettingsVisualTokens：尺寸、颜色、motion、局部字阶。
- SettingsShell / SettingsNavigation：窗口两列与稳定 page ID。
- SettingsRow：标题/说明的 Star 列 + Auto 控件列；支持窄窗堆叠。
- SettingsSection：组标题与轻分隔，不默认套卡片。
- SettingsPreview：静态示意或已有角色路径；明确生命周期。
- SettingsSaveStatus：Idle / Pending / Saved / Error，成功信息安静显示，错误持续。

### 推荐导航实现

优先评估标准 NavigationView，固定设置菜单项并隐藏它自身多余的返回/设置入口；侧栏底部用 PaneFooter 放组件显隐操作。用现有按钮状态、AutomationProperties、焦点模型做定制，不重写成只有指针命中的 Canvas。

如果标准模板的额外空白无法满足此图，再用标准 ListView/选择项实现窄的五项侧栏。两种方案选一种，不能同时维护两套路由。不要为了几像素差异立刻重写控件模板。

### 窗口框架是本次最容易漏的地方

当前双区域窗口与手动移除窗口样式是配套的。仅把 XAML 改成侧栏，会留下切角、透明空隙、不能缩放或双关闭按钮。

优先采用正常 OverlappedPresenter 与系统标题栏，移除自画重复的 caption 按钮。若后续需要内容延伸到标题栏，再依据微软文档保留系统 caption 与命中排除，不手搓拖动/最大化的全部行为。

关闭设置仍调用 Hide/刷新待保存任务，不直接 Quit；通用页退出才退出驻留程序。Escape 在弹层、HEX/快捷键录制中的优先级必须明确。

## 7. 保存、状态与交互契约

1. 不把拖动滑块的每个 ValueChanged 都变成独立磁盘写；沿用现有 250 ms 合并。
2. 原生保存提示由真实异步结果驱动；HTML 的约 500 ms 演示延迟不能进入产品代码。
3. 保存失败不能显示“已保存”，不能仅因切页就清掉警告；保留 LastSaveFailed 和已有退出选择。
4. 重试仅重发用户当前未成功保存的意图；复用 pending/rebase，不能拿旧的整份 WidgetPreferences 覆盖最新位置。必要时保留失败请求以支持显式重试，不能只在 UI 中把错误状态改成成功。
5. AppearanceRevision 及临时颜色预览机制保留；较旧的保存完成不能清掉用户更新的颜色。
6. 定时状态刷新只改对应标签/开关，不每秒重新 BuildContent。Refresh 不跳页、不抢焦点、不把用户输入中的 HEX 恢复成旧值。
7. 本窗口仍只创建一次、Hide 后复用；关闭期间停止状态计时器、预览跟随、动画，Dispose 时解除事件。
8. 导航 hover 只反馈；点击/键盘确认才选页。不存在“移入切页，再点击又切一次”的双触发。
9. 新壳只保留一个清晰的关闭入口；显隐桌面组件不等于关闭设置，也不等于退出进程。

## 8. 动效与短工作区规则

- 侧栏选中底色/图标颜色：100–140 ms；当前页语义立即更新。
- 内容切换：约 160 ms opacity；无整页横穿、文字 blur 或等待弹簧结算后才能点击。
- 开关：约 170 ms 的 thumb 位移；按钮只轻微 pressed，不普遍添加弹性。
- 形式/颜色：80–140 ms 局部交叉变化；预览与控件值同步，不做大幅弹跳。
- 预览视线：最大约 ±2 DIP、约 170–200 ms，离开复位。
- 系统或用户减少动态：直接状态替换或极短淡化；数据、选择与错误保持完整。
- 系统高对比：回到系统 Window / WindowText / Highlight，移除半透明材质；不能继续坚持浅灰提示。

默认窗口按工作区换算：fitWidth = workAreaPixels.Width / scale - 安全边距，fitHeight 同理；推荐尺寸再取 min。不要用硬编码的最小高度把系统缩放用户顶出屏幕。

范围：
- ≥820 DIP：约 190 侧栏 + 单列正文。
- 620–819 DIP：160 或 148 侧栏，减少左右 padding；复杂行控制区缩短或放到下一行。
- <620 DIP：紧凑顶部分类或可展开的带文字导航；不能只留下不明图标。HTML 为横向可滚动分类示意。
- 很短窗口：正文真实滚动、页脚固定；侧栏分类可独立滚动，底部操作不能覆盖最后一类。
- 1366×720 @200% 等情况必须以实际 WorkArea/DPI 算可用 DIP。不要将“360 px”当成“360 DIP”的窗口承诺。

HTML 已提供尺寸切换，但未在自动浏览器中确认这些像素布局。原生实现阶段需要实测后再关闭此项。
