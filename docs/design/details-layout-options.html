借鉴了什么（都是成熟做法）

不是凭空设计：三个来源各取一条规则，拼成这套“顶部陪伴 + 底部 Dock”。

iOS · Tab Bar

底部切换、2–5 个目的地、图标 + 文字、选中项着色。我们取：底部、5 项、当前项带名字。

Apple HIG · Tab bars

Material 3 · Navigation Bar

3–5 个目的地、选中项有胶囊指示器、图标在上文字在下。我们取：选中胶囊 + 图标文字组合，但高度收小到 48，适配 360 卡片。

Material 3 · Navigation bar

macOS · Dock

悬停才出名字、选中项浮起、整体半透明。我们取：悬停出名字牌 + 选中项白色胶囊，这是你这套 UI 最像 macOS 的地方。

Apple HIG · Dock
为什么推荐方案 1：
  • 陪伴有了明确任务：顶部那个小把手就是陪伴，点它回首页（时间胶囊），不再是“一根带眼睛的长条”。
  • 顶部安静：只有一个小把手，封面可以更大、正文更松；不再挤 5 个槽 + 圆按钮。
  • 底部 5 项刚好：音乐、小组件是真实页面；时钟/专注/随记标成“预览”，悬停出名字，不假装是成品页。
  • 对称：Dock 居中、左右一致；删除右上圆按钮后，卡片终于左右配重。
