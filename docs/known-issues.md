# 0.1 已知限制与文档勘误

本页描述当前可核实的边界，不把历史内部审查的所有条目都当作未修复缺陷。

## 发布与验证

- 0.1.0 安装包未代码签名。请从本仓库 Releases 下载并核对 SHA-256；遇到系统提示时确认来源，不需要关闭 Windows 安全防护。
- 已完成自包含编译、发布附件大小与摘要核对，以及展示页的简单交互与响应式检查。**尚未完成干净 Windows 11 虚拟机中的安装 → 启动 → 卸载验证。** CI 编译或源码检查通过也不能替代它。
- 首次发布的安装包内 `THIRD-PARTY-NOTICES.md` 抬头和导语误写为 0.2.0，实际程序与许可清单版本为 0.1.0。当前分支已修正；原安装包及 `v0.1.0` 标签保留不变，最新勘误见 Release 和当前第三方声明。更正版本标注不改变第三方原始许可文本。
- 历史内部设计、工作记录和过期审查已从当前公开目录撤下并本地归档；它们仍可通过旧 Git 历史及标签访问。本次未重写历史，也未移动已发布标签。

## 功能边界

- 音乐依赖网易云提供的 SMTC 会话及能力，未提供有效时间轴时不支持跳转；没有账号登录、歌单同步或收藏功能。
- 首页入口和文件夹区域仍属于早期体验：非首页的返回首页操作有命中区和无障碍名称，但当前缺少可见返回箭头。首页标签已接入材质相关墨色选择，不能继续沿用旧报告“始终使用暗色字”的结论；不同背景下的实际可读性仍需界面验收。
- 默认大展开页为音乐，之后记住上次实际页面；这是当前行为，不将其列为故障。官网和 README 只展示音乐小展开。
- 本地插件在主进程中运行，不能隔离恶意代码或原生崩溃；无法可靠卸载的插件需要重启。
- 液态玻璃额外消耗捕获与图形资源，环境不支持时回退基础材质。参见 [隐私说明](privacy.md)。

问题反馈请提供应用版本、Windows 版本、显示缩放与复现步骤。请勿把旧测试报告中的批次数值当作当前安装包的测试结果。
