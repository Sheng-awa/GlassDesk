# 状态与动作规格

显示形态为 Capsule / Peek / Details，隐藏原因独立管理。尺寸使用 DIP；当前 150% 环境对应 348×72、540×198、540×696 像素。

| 输入或事件 | 行为 |
|---|---|
| 胶囊连续悬停 350ms | 小展开；快速经过不展开 |
| 小展开离开 450ms | 收回；等待期间返回取消收起 |
| 点击封面、标题或主体 | 大展开，并保持到主动关闭 |
| 上一首、播放暂停、下一首 | 只提交当前来源允许的媒体命令；不向主体传播 |
| 大展开关闭按钮 | 收回胶囊 |
| 主体移动超过 6 DIP | 进入拖动，取消点击与悬停计时；位置跟随真实指针位移 |
| 进度拖动 | 仅可用时间轴与 Seek 能力下预览，释放时提交一次范围内 Ticks |
| 新切入最大化应用 | 收回胶囊；仍允许之后正常展开 |
| 外部普通视频/无边框全屏 | 自动隐藏；已绑定快捷键可临时唤出胶囊，再按隐藏 |
| 退出全屏 | 清除临时状态，按手动隐藏状态决定是否恢复胶囊 |
| 显示器消失 | 迁移到主屏，并限制位置在工作区 |
| 歌曲或封面更新 | 更新内容，保持形态 |

动作时长：胶囊→小展开 220ms，小展开→大展开 260ms，胶囊→大展开 280ms，收回 220ms，吸附 120ms。MotionController 保存当前呈现和速度；重定向从当前状态继续，输入不会被动画锁住。减少动画时直接呈现清晰的目标状态。

保存胶囊水平中心与顶边锚点。大卡片优先保留锚点，靠近边缘时向内展开；收起返回胶囊锚点。吸附阈值为工作区边缘或水平中线 12 DIP。工作区不足时限制大卡片高度，主体滚动，底部控制与关闭入口保持可达。

暂停保留歌曲与封面。仅有效来源时间轴才推算进度，使用单调时钟并在暂停停止；唤醒后重新读取来源。缺少时间轴时显示不可用提示，禁用 Seek。没有准确网易云会话时显示真实本地时间、日期、星期与连接说明。

设置窗口正常参与窗口管理；宿主、阴影和设置都不被当作外部应用。原生宿主默认不激活、不进入任务栏或 Alt+Tab。独占全屏游戏不采用注入或强制覆盖。
