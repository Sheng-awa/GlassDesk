# GlassDesk 0.2.0 能力矩阵

本机最终批次及实测数字见 [验收报告](test-report.md)，完整发布文件指纹见 `verification/release-binary-batch-0.2.0.json`。保留 C#/.NET 10、WinUI 3/Composition 和 C++ 原生层，一个主组件。

| 能力 | 实现与限制 | 本次证据 |
|---|---|---|
| 网易云真实媒体 | 精确 cloudmusic.exe、过期元数据/封面门控、真实能力判断 | 最终安装版真实封面、元数据和播放状态；完整重启/混合播放器 GUI 组合未齐 |
| 播放时间轴 | 只有有效范围才显示并允许跳转 | 本机客户端不支持，Seek=false；不伪造进度 |
| 暂停五秒 | 只改变胶囊，展开内容保留；会话变化独立计时 | Core 边界检查及真实暂停读回 |
| 六种时钟/音乐形态 | 统一尺寸模型、局部清晰文字、展开保持顶部与水平中心 | 应用驱动 1,000 次切换；音乐详情无时间，小展开时间居中 |
| 单陪伴球 | 每次展开随机固定槽位，各槽位固定大小，身体和眼睛留在边界内 | 小展开 44/40/36/36、大展开 52/40/36/36 DIP；自然回应，无固定 8 秒轮播 |
| 鼠标跟随 | 胶囊外继续平滑限幅，独立设置保存；隐藏/简化动画停止轮询 | 当前 Windows 输入桌面的 GetCursorPos，不能跨锁屏或安全桌面 |
| 播放交互动画 | 轻压至94%，220 ms 播放/暂停矢量变形，实际命令立即发送 | 已保留用户确认的实现与实机证据；系统/应用减少动画共同生效 |
| 真实音频波浪条 | 精确进程树 loopback、25 Hz FFT、8 段；失败/暂停/隐藏归零 | Audio42；最终原生已知信号46项；首次分析114.59ms，完整UI延迟未测 |
| 液态玻璃 | WGC→GPU裁剪→原创HLSL→Composition；宿主拥有采集worker，关闭/隐藏退出 | 深/浅/复杂真实背景、两轮原生各100启停、生产GUI100启停、精确排除恢复、异常回退/恢复 |
| 本地功能插件 | 独立ALC、内容/命令/配置/角色/材质贡献、配置保留、异常撤销 | Plugin33含各100次生命周期；进程内可信代码，不承诺隔离原生崩溃 |
| 全屏与可见性 | 手动隐藏与全屏临时状态分开 | Core组合通过；真实cs2全屏自动避让通过，手动隐藏完整组合未完成 |
| 输入与设置 | NOACTIVATE、真实拖动、四角/阴影穿透；五标签、有限宽度、纵向滚动 | 生产输入证据与响应式设置；放大文字/其他DPI覆盖未齐 |
| 连续驻留 | 最终同一PID 130.98分钟；扣预热后的完整60分钟 CPU0.430% | 压力仪器/设置保留时165.57–215.01MiB，后段平台；正常模式312秒样本78.64–89.09MiB、CPU0.253%；200MB压力目标未达 |
| 实际呈现 | ROI像素呈现探针，保留长间隔及观察器漏采 | 受控底板30秒运动P95=15.846ms、max23.830ms，保留1,309漏采；不扩大为稳定60FPS保证 |
| 安装与迁移 | 当前用户、自包含、原AppId、V1→V2、卸载保留配置 | 本机首装/覆盖升级/卸载重装、源码逐文件及发布哈希核对 |
| 环境 | Windows11 25H2 x64、150%实机 | 其他DPI/混合屏/干净系统、真硬件失效/睡眠/断屏未验证，候选试用包 |
| 范围外 | 歌词、收藏、天气、月历、成长、实际换装、在线市场 | 未实现，不展示假功能 |
