## 2. 圆角统一（这次最重要的一条）

### 为什么现在看着“不对劲”

现在同一个界面里同时有 **4 / 10 / 12 / 20 / 23 / 24 / 26 / 28**，ColorPicker 还是直角。
圆角不一致 = 眼睛每看到一块都要重新校准；相邻两层圆角不平行 = 轮廓显得歪。

### 三条规则（记住这三句就够）

1. **同一层，同一个圆角。**
2. **紧贴的两层要“同心”**：内圆角 = 外圆角 − 间距（结果小于 8 就取 8）。
3. **按钮、开关、名字牌用全圆**；只有条形元素（频谱、进度、导航小条）用 2–4。

### 四档圆角

| 档位 | 值 | 用在哪 |
|---|---|---|
| 外壳 | **24** | 胶囊/小展开/大展开外壳、设置窗口面板、顶部丝带外框 |
| 卡片 | **16** | 设置里的卡片、小组件卡、封面、预览底、菜单浮层 |
| 控件 | **10** | 输入框、下拉框、色块、ColorPicker、小图标底 |
| 全圆 | **半高/2** | 所有按钮、开关、名字牌、提示条 |

### 现在 → 改成（逐项）

| 地方 | 现在 | 改成 |
|---|---|---|
| 设置窗口面板 | 24 | **24**（不变） |
| 设置卡片 | 24 | **16** |
| 设置输入框 | 24 | **10** |
| 顶部丝带外框 | 28 | **24** |
| 丝带选中底 | 23 | **20**（外 24 − 内缩 4，同心） |
| 封面 | 20 | **16** |
| 小组件卡 | 20 | **16** |
| ColorPicker / 色块 | 直角/默认 | **10** |
| 关闭按钮 | 20 | **全圆** |
| 名字牌（新增） | — | **全圆**（高 20–22） |
| 频谱/进度/小条 | 2–4 | **不变** |

> macOS 还有一层“连续曲率”（squircle），WinUI 默认是正圆弧。这一步先不做（要改自绘），**先把半径统一**，80% 的“舒服感”就回来了。

参考：
- Apple 同心圆角（嵌套圆角共享圆心）：[concentric(minimum:)](https://developer.apple.com/documentation/swiftui/roundedrectangularshapecorners/concentric(minimum:))
- 设计技能里的同心圆角写法：[Keep nested corner radii concentric](https://github.com/pproenca/dot-skills/blob/master/skills/.experimental/adversarial-ios-design/references/layout-concentric-corners.md)
- Windows 11 几何规范（同层一致、不同尺寸不同半径）：[Geometry in Windows 11](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/geometry)
- Material 3 形状阶梯：[Corner radius scale](https://m3.material.io/styles/shape/corner-radius-scale)

## 3. 布局：顶部陪伴把手 + 底部导航（按你的草图）

你说得对：长条不该背“陪伴”的锅。你的草图给了更好的答案——**顶部只放陪伴，点它回首页（时间胶囊）；导航整体搬到底部。** 这样：

- 陪伴有了明确任务：**首页把手**；
- 顶部安静，封面可以更大；
- 底部有足够空间放名字，5 项不再挤；
- 右上圆按钮删除，卡片左右配平。

### 3.1 顶部：陪伴 = 首页把手
- 位置：顶部居中，58×28 小胶囊，眼睛在里面。
- 行为：点一下 → 收起回胶囊（首页/时间）；悬停出现“回首页”小名字牌。
- 胶囊、小展开形态完全不变；眼睛不再长在导航长条上。

### 3.2 底部：两套导航，选一个
**方案 1（推荐）· 浮动 Dock**
- 320×48 深色胶囊，距底 16，圆角 24。
- 5 项：音乐、小组件（真页面）+ 时钟、专注、随记（预览）。
- 选中项：白色胶囊 + 图标 + 名字；未选中：图标 60% 白；预览项 70% 透明。
- 悬停任意项：上方弹出白色名字牌（就是你发的 LINK 那种）；预览项名字后加“（预览）”。
- 为什么好：最像 macOS Dock / 你的参考图；选中项自带名字，未选中不吵；卡片底边有“托盘”感。

**方案 2（备选）· 全宽 Tab Bar**
- 底部 62 高全宽栏，5 项图标 + 文字始终可见，选中项蓝色胶囊底。
- 更像 iOS / Material；信息最全，但底部更重，容易和播放控制抢注意力。

### 3.3 内容怎么排（音乐页 360×476 / 小组件页 360×512）
- 音乐页：把手 y14 → 封面 168 @y70 → 标题 y246 → 歌手 y274 → 时间轴 y300 → 播放控制 y340 → Dock y412（距底 16）。
- 小组件页：把手 y14 → 标题/添加/编辑 y62 → 卡片 y104（两小 + 一宽，可滚动）→ Dock y448（页高 512）。
- 时间白板、8 根频谱、播放/暂停动画、陪伴液体移动：全部不动。

### 3.4 你的草图里那个底部小圆
我暂时理解为“滚动/拖拽指示”或“回到顶部”，没有画进方案。如果它指的是别的（播放/首页/展开），告诉我再加。

## 4. 小组件板：不是重做，是把“没做好”的地方收干净

功能全保留（时间/日期卡、多实例、改大小、配置、删除、拖动排序、添加菜单）。只改观感：

1. **卡片文字从 3–4 层减到 2 层**
   - 时间卡：现在“时间 / 02:23 / (UTC+08:00) 北京, …” → 改成 **02:23 + 北京时间**
   - 日期卡：现在“日期 / 19 / 2026年10月 / 星期一” → 改成 **19 + 10月19日 · 周一**（年份只在不是今年时显示）
   - 时区、年份这些细节保留在“配置”里，卡片上不堆。
2. **添加 / 编辑不再是纯文字**：添加 = 蓝色小胶囊；编辑 = 文字按钮带 hover。功能不变。
3. **卡片圆角 20 → 16**，卡片底加很淡的一层纸面和 1px 亮边，让它从玻璃上“浮起来”。
4. **导航下面那行**现在会变成“小组件 · 时钟（预览）”（因为鼠标在槽上）→ 改成只显示当前页；槽名交给第 3 节的名字牌。
5. 右上圆按钮删掉后，标题行恢复左右配重。

## 5. 设置窗口：只去噪，结构不动

**保留**：五个分类、顶部丝带、两列布局、所有开关、插件、诊断、热键、透明度/模糊等全部功能。

只做 5 件事：

1. **材质固定**：设置窗口不再跟着“透明度”滑杆变；背景透一点就够，文字要清楚。
2. **去重复**：删掉 header 的“GlassDesk”大标题（页面名已经有了）；只留一个关闭入口（右上 X + Esc，删页脚“关闭设置”）。
3. **去噪音**：常驻绿色提示改成 1.5 秒中性提示；英文 “Disabled” 改中文；删“UI 预览不修改…”这类开发期文案。
4. **修实机看到的 3 个 bug**：外观页“显示星期”被底部裁掉；插件列表被裁；ColorPicker 是直角且太大（圆角 10、高度收到约 240）。
5. **统一圆角**：设置卡片 24→16，输入框 24→10，关闭按钮全圆；“隐藏组件”保留功能，从大胶囊缩成小按钮放 X 左边。

## 6. 主窗口小修（可选，不着急）

不动的：耳朵/角、时间白板、8 根频谱、陪伴液体移动、播放/暂停动画、深色主题、功能删减、设置结构重排、装字体、加第三方库。
