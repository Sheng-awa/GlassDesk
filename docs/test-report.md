## 液态玻璃

真实路线为 WGC 显示器纹理→GPU 裁剪→原创 HLSL 预滤波、两遍模糊和圆角边缘折射→Composition。内容层保持清晰，未引入 Qt 或复制参考着色器。深、浅、彩色格背景均取得同一帧原图和材质输出；彩色格与底层文字确实透入材质，边缘采样发生弯曲，中心柔化。原图中没有自己的封面、按钮或影子，避免反馈。证据为 `artifacts/final-acceptance/material-{dark,light,complex}.png` 及各自 `-raw.png`；输出的是材质层，最终浮点圆角裁切和前景仍由宿主合成，不能把它冒充整张最终 UI 截图。

原候选版在 60 次启停后出现约 2 GiB 的 Windows 共享 GPU 分配累积。关闭/刷新设备、独立设备和重用 frame pool 的尝试没有消除该趋势，未列为成功。最终版将 WGC 放入宿主拥有的采集子进程，采用匿名控制通道和 GPU 共享纹理；关闭/隐藏时退出，宿主异常退出时由 kill-on-close Job 清理。

| 验证 | 结果与范围 |
|---|---|
| 原生真实采集循环 | 两轮各 100 次；每轮真实收到帧、关闭后 surface 消失、原窗口采集属性精确恢复、对应 worker 退出 |
| 生产 GUI 循环 | 安装版 PID 41588，cua-driver 100 次开→Running、关→Disabled；主进程不重启；`liquid-gui-100-final.json` |
| 采集排除 | 主体及阴影读回 `0 → 17 → 0`；生产 active、fallback 和 hidden 状态也独立读回 |
| 隐藏与恢复 | 实际隐藏时窗口不可见、worker 数为 0、主体 affinity=0；重新显示后 Running，开关保持 true；`hidden-liquid-resume.json` |
| 意外采集退出 | 主动终止唯一的直属 capture worker 后，设置显示 `Fallback … enabled intent retained; retry in 5s`，主体/阴影 affinity 均恢复 0；重试创建新 worker 并恢复 Running，同一宿主仍存活；`fallback-recovery.json` |
| 宿主异常退出 | 原生 fixture 直接 ExitProcess，外部核对 worker 已退出；`worker-ownership-result.json` |
| 真实硬件故障 | 未实测 GPU 移除、真实睡眠或断屏；不能用采集进程退出替代这些环境 |

资源开销按范围分别记录。100 次 GUI 生命周期期间的 55 个 Windows 计数样本中，宿主 GPU 记账峰值 112.39 MiB，worker 77.43 MiB，两进程记账之和最高 189.75 MiB，worker 私有内存最高 51.52 MiB。共享纹理可能在两个进程重复记账，不能把其和解释成新增物理显存。该组包含反复创建、设置窗口与观察器，不是静止增量成本。另对生产材质启用后、相同 worker 连续存活的 27 个区间（合计 422 秒）分别计算 CPU：宿主 0.197%、worker 0.058%、DWM 1.648%（均按16逻辑处理器归一化）。DWM 包括其他桌面工作，不能把此数值全归因于液态玻璃；这组处于音乐暂停/详情与背景验收场景，不与核心播放基线混为同条件增量。原生隐藏 fixture 的另一组 52 个系统计数样本峰值 34.33 MiB、结束 17.92 MiB，也不能替代生产应用数字。

生产 100 次循环末尾 GPU filter 平均约 0.011 ms、最大 0.195 ms；这是宿主滤镜时间戳跨度，排除 worker 的完整 WGC 生产者与 DWM 成本。复杂背景详情页另观察到更高跨度，故不承诺整个液态玻璃仅耗 0.011 ms。正常渲染没有 CPU 像素读回，只有显式单帧验收输出读取图像。

## 播放、布局、输入与动画

- 最终构建保留用户确认的单陪伴球；每次展开随机选固定槽位，音乐小展开 44/40/36/36 DIP，大展开 52/40/36/36 DIP，身体和眼睛在卡片内。移动/缩放 650 ms 与表情同步重定向，无固定 8 秒轮播。
- 小展开系统时间居中；大展开不显示时间或底部操作回执。日期、星期和胶囊外眼睛跟随均使用现有设置保存；最后独立核对开关 UI 与实际配置文件的关闭/开启读回。桌面光标读取不跨锁屏或安全桌面。
- 播放按钮轻压至 94%，快速点击保留按压反馈，三角与暂停双条 220 ms 矢量路径变形。媒体命令不等动画结束；App 与系统减少动态效果共同生效。最后重装版通过实际按钮验证上一首/下一首，内容指纹变化且回到原曲，暂停也读回成功；应用简化动画开/关均验证 UI 与实际配置保存，结果见 `final-media-controls.json`、`reduced-motion-final.json`。系统全局动画开关的 GUI 联动未单独实测，不扩大为已覆盖全部系统场景。
- 本次追加的设置宽窗/窄窗、跟随开关实际持久化及本地文件选择器导入、启用、操作、移除已实机核对，示例插件只装入隔离目录；`follow-persistence-final.json`、`plugin-gui-final.json` 保留结果。最后 App/NativeBridge 字节包含实际播放、暂停、上一首、下一首与封面/文字切换的既有实机验证。全屏手动隐藏状态分离已通过 Core 组合检查。最后实际 cs2 全屏前台（2560×1600）时，组件可见性读回 false，自动避让实机成立；原计划“手动隐藏→全屏临时唤出→退出恢复”的完整独立窗口组合仍未完成，因为测试窗口在建立正常场景基线前被正在使用的全屏游戏取回前台，不把该尝试算为通过。临时测试快捷键随隔离进程退出注销；`fullscreen-real-game.json` 保留范围。真实输入焦点、拖动和四角/阴影跨进程点击有独立生产证据，位于 `artifacts/qa/release-focus-play.json`、`release-real-drag.json`、`release-corner-shadow-events.jsonl`。本次追加的采集层不替代这些输入验收。
- 最终 Native DLL 另通过 46 项真实已知音频检查，1.5 kHz 信号连续 29 次落在预期频段，首次分析检测 114.59 ms，其他进程捕获 RMS=0；`audio-native-frozen.log`。这不包含最终屏幕首次呈现；完整 UI ≤150 ms 仍未验证。真实多播放器同时播放、客户端重启与完整静音 GUI 组合的验证范围仍不齐，不标为全覆盖。
- 本机网易云没有有效媒体时间轴，Seek 能力为 false；界面隐藏不可用进度，不伪造时间。

实际呈现探针采用 Desktop Duplication 的 ROI 像素变化时间戳，而非 16 ms 定时器。先前最终二进制 40 秒样本有 7,789 个桌面帧、916 个 motion intervals、P95=12.789 ms、漏采桌面帧 499；背景未充分受控，不能由此宣布稳定 60 FPS。随后对最终安装二进制增加独立单色静态底板，在实际三态重定向期间采样 30 秒：4,414 个桌面帧、2,626 次几何变化、1,288 个 motion intervals，平均 9.191 ms、P95=15.846 ms、最大 23.830 ms，超过 25/33.4 ms 的运动子集间隔均为 0；同时记录漏采桌面帧 1,309、protected=0。底板覆盖整个组件动画包络，前后桌面上下文图保留在本机。该组使用 600 次应用驱动切换，与驻留批次的 1,000 次独立，不相加冒充驻留次数。所有时间戳、长间隔与观察器漏帧均保留；运动子集不能证明物理屏幕每帧无遗漏，兼容环境中的稳定 60 FPS 仍不作全面通过结论。结果为 `presentation-controlled-summary.json`，原始散列在验证摘要中。
