# 验证记录

[release-0.1.0.json](release-0.1.0.json) 记录当前公开安装包的文件名、摘要及实际验证边界，是首次公开发布的索引。

本目录其他早期 0.1 基线 / 0.2 原型 JSON 为历史开发批次。它们不是当前公开安装包的验收结果，不能将其中安装、升级或压力测试状态套用到当前版本。

干净 Windows 11 虚拟机安装 → 启动 → 卸载验证仍未执行。安装包已生成与安装包已执行是不同状态；报告必须分别描述。

`CurrentBranchCI` 单独记录分支代码的 Windows 编译与隔离检查结果、对应提交和前序失败记录；它不表示公开安装器已经执行，也不替代 Windows 11 桌面安装验收。
